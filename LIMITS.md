# Границы «Синергии» 5.29.0

Здесь собрано, чего продукт не делает, что не проверено и о чём нельзя говорить. Если README или презентация расходятся с этим файлом, верен этот файл.

## Медицина

- **Не медицинское изделие.** Не диагностирует, не лечит и не назначает тренировки. Программу занятий человек согласует с реабилитологом или протезистом (онбординг, `docs/LEGAL.md`).
- **Перенос навыка из игры на протез не доказан** — ни у нас, ни в целом для игр с ЭМГ. Исследования, на которые опирается механика (Garske 2021, Dupan 2025, Maas 2024), — малые выборки, часто здоровые участники. Пользы мы не обещаем (`docs/RESEARCH.md`).
- **Пользу для фантомной боли не заявляем:** в РКИ Lendaro 2025 выполнение фантомных движений не превзошло их представление.
- Метрики «Проверки навыка» и «игровая пропускная способность» — игровые, по мотивам Motion Test / TAC и теста Фиттса. Это не клинический тест.
- **Повторы после попытки, «стабильно / мерцает», лёгкая первая неделя, быстрый старт (5.17–5.18)** опираются на исследования здоровых участников и наблюдательные данные о пациентах после инсульта (`docs/RESEARCH.md` §11). Что они помогают людям с протезом, не проверено. «Мерцает» — подсказка, а не мера навыка.
- **Погрешность проверки (5.18)** считает попытки независимыми и одинаково трудными. Это модель, а не свойство человека: утомление внутри проверки и разные расстояния целей Фиттса она не учитывает.

## Пользователи

- **Живые игроки с протезами в игру не играли.** Баланс проверен ботом и моделью новичка (`tests/human.test.mjs`).
- **Не проверено:** TalkBack и VoiceOver (в том числе озвучка вердиктов «Полёта» и «Мастерской»), кнопочный переключатель на телефоне; вибрация 5.17 на настоящем телефоне — в BlueStacks её нет.
- Протокол проверки гипотез — `docs/USABILITY_PROTOCOL.md`. Результатов нет (`docs/USABILITY_RESULTS.md`), и вымышленными они не заполняются.

## Датчики и сигнал

- Смена хвата повторяет протез «Моторики» по его инструкции в Motorica Start, а не по замеру на протезе. Удержание по умолчанию — 1,00 с, блокировка — 1,6 с: так стоит экран настроек Motorica Start в его открытом коде (5.29). Это значение экрана приложения, а не замер на протезе; своё время ставит протезист.
- Настоящие Motorica Start и ATTILAN не подключались. Снимок Motorica Start v1 игра читает: формат взят из открытого кода Motorica Kart и проверен тестами, а не на приложении. Стороннее приложение к службе игр Motorica Start не привяжется: разрешение `CONTROL_GAME` в её открытом коде объявлено с `protectionLevel="signature"` (ветка от 20.10.2026). Путь — подписанный хост «Моторики», который встраивает «Синергию». Пороги протеза (`getLatestThresholds`) игра читает, но с настоящим приложением это не проверено. «Тот же уровень сигнала» — это тот же порог на тех же уровнях 0…255. Своё сглаживание (35 мс) и гистерезис у игры остаются, а как фильтрует сигнал сама кисть, в коде приложения не видно. Формат эмулятора организатора неизвестен до 28.10: адаптер — `parseExternal()` в `src/input/bridge.js`.
- **Семь жестов — гипотеза команды** до публикации задачи. Набор задан в одном файле, а его замена проверена учебным прогоном. Учебный прогон меняет один жест из семи. Если задача возьмёт обучение жестам UBI4 из Motorica Start (покой и семь классов), классов станет восемь — это больше одной правки (`PLAN.md` C.3, шаг 8). До тех пор чужой класс — покой: кисть стоит, под полем написано, что пришло; «Флексию» и «Экстензию» нарисованная кисть не показывает.
- Подстройка покоя под дрейф и Bluetooth-датчики не проверялись на реальном теле. Лаборатория LDA работает на синтетической ЭМГ. Карточка модели — `docs/MODEL_CARD.md`: это не модель пациента, порог теста — доля верных ответов выше 0,85 на синтетике.

## Платформы

- **APK** подписан отладочным ключом той машины, где его собрали. Поверх сборки с другой машины он не встанет: ключ команды — через `release.yml`.
- **Проверено на APK:**
  - BlueStacks (Android 7.1.1, WebView на Chrome 119) — 5.16.0, 5.17.0 и 5.18.0 (обновление поверх с сохранением данных); 5.20.0 (сборка `c591c48`, до исправлений дня кожи) — установлен и запущен 20.10.2026; 5.19.0 не ставился;
  - BlueStacks (Android 11) — 5.12–5.13.
- **Не проверено на APK:**
  - телефоны с Android 12+ (системная заставка из иконки);
  - слабые телефоны.
- **CI на GitHub не выполнялся.** Репозиторий https://github.com/KonkovDV/Synergy приватный. 20–21.10.2026 задания не стартовали: GitHub сообщил, что у аккаунта не прошла оплата или исчерпан лимит расходов. Шаги кода до запуска не дошли. Цифры таблицы README сняты локально — дата и среда в `docs/evidence.json` (`PLAN.md` B.1).
- **Встраивание** проверено так:
  - Web — e2e на двух origin;
  - Kotlin — скомпилирован против Android API 29;
  - React Native — проверка типов;
  - Swift, Flutter, Unity не компилировались;
  - ни один хост не запускался на устройстве.

## Данные и право

- Данные хранятся только на устройстве. Аккаунта, сервера и аналитики нет. Отчёт для специалиста содержит сведения о здоровье, и человек сохраняет его сам.
- Возрастная категория 0+ — предложение, её подтверждает юрист команды. ФИО авторов (`AUTHORS.md`) и ответ организатора о наработках до 28.10 — за командой.
