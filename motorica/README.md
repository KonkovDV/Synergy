# План сотрудничества MOTUS Lab и ГК «Моторика»

Презентация о дальнейшей совместной работе. 71 слайд в десяти разделах — в порядке разговора за столом «Моторики»: кто за столом и что важно каждому креслу → «Моторика» и рынок → где теряются деньги и пользователи → решение → пакеты работ → бизнес-эффект → команда и формат → план и пилот → доверие и риски → решения. Листать — колесом мыши, кнопками «Назад · Все слайды · Дальше» внизу экрана, стрелками или свайпом; «Все слайды» (G) открывает оглавление. С 23.11.2026 у колоды есть маршрут читателя, с 24.11.2026 — «Нейротехнологии и инновации»: он собран под департамент нейротехнологий «Моторики» (NEMO Sensitive, остеоинтеграция, нейростимуляция) и её инновации — 19 слайдов на ≈15 минут, свой PDF и ссылка `?route=innov`; на телефоне по этой ссылке видны только его слайды и плашка маршрута. К нему добавлены слайды «Нейротехнологии и инновации: шесть ответов на ваши вопросы», «Нейропротезы, проверенные временем» (Case Western, e-OPRA, ETH, EVOKE, OPRA), «Мировая планка» (лучшее у Ottobock, Coapt, PSYONIC, Phantom Neuro, Meta и в РКИ по фантомной боли — уже в нашем плане), «Сто решений геймджема — один конвейер до пользователя» и «Требования 2026» (наука, нормы России 2025–2026, открытые стандарты LSL, BIDS-EMG, LibEMG, MyoSuite, WCAG 2.2). Основа — реестр рисков «Моторики» из её годового отчёта 2025: меры по 13 из 30 ключевых рисков есть в наших пакетах, в том числе по О6 «Кадровый голод» и РЕГ1 «Изменения в законодательстве» из самой опасной клетки карты. Дальше — правила рынка, кто наступает на пятку (Steplife, «Максбионик» и ГК «Метиз», госкорпорации, новые игроки), сравнение по двенадцати направлениям — где «Моторика» впереди и где отстаёт, три ответа на три давления конкуренции из годового отчёта, голос пользователей по всем отзывам RuStore, взгляд восьми кресел руководства, боли компании с цепочкой «решение → доказательство → процесс → эффект», этапы пациентского пути, вклад в инвестиционную историю к IPO, бизнес-эффект по семи рычагам, команда и медицинское ПО с врачом в цикле, 11 пакетов работ в четырёх треках, пилот на 8 недель, данные, право, проверяемость каждого числа и решения на встрече.

## Как устроено

Один источник — модули в `tools/motorica/`:

- `data.mjs` — факты о «Моторике» и конкурентах с источниками, кресла, слабые места, пакеты работ, стыки, роли, риски, решения;
- `model.mjs` — модель эффекта: база 2025 года, сценарии, рычаги L1–L7;
- `slides.mjs` — слайды: раздел, маршрут, заголовок, данные, речь, источники; ссылки между слайдами — `{#layout}` и `{#wp:WP5}`;
- `render.mjs` — HTML и SVG каждого макета, без атрибутов `style` (строгая CSP).

Из них `tools/motorica-site.mjs` собирает `index.html`, `plan.html` (из `PLAN.md`) и `sw.js`, а `tools/motorica-deck.cjs` открывает ту же страницу в Chromium (`?print=1`) и печатает PDF, по `?print=1&route=innov` — PDF маршрута «Нейротехнологии и инновации», снимает слайды для PowerPoint и `og.jpg` и пишет `slides.json`. Поэтому сайт, PDF и PPTX не расходятся. Калькулятор сайта (`app.js`) и Excel-книга (`tools/motorica-model.py`) считают по тем же формулам, что `model.mjs`; проверки сверяют все три.

## Как пересобрать

```bash
npm i --no-save pptxgenjs@3.12.0 sharp@0.34.4 react-icons@5.5.0 react@18.3.1 react-dom@18.3.1 qrcode@1.5.4
```

```bash
node tools/motorica-site.mjs && node tools/motorica-deck.cjs && node tools/motorica-site.mjs
```

```bash
python3 tools/motorica-model.py && python3 tools/motorica-model.py --check
```

```bash
npm run check:motorica && npm run check:motorica-page
```

Второй запуск `motorica-site.mjs` нужен, чтобы ссылки на свежие PDF и PPTX получили новые `?v=` и размеры. Для `--check` нужен LibreOffice: он пересчитывает книгу и сверяет итоги с `slides.json`.

### Колода в Figma — слоями

```bash
node tools/motorica-figma.cjs
```

Скрипт кладёт в `dist/figma/` четыре самодостаточных HTML-снимка колоды: слайды 1–20, 21–40, 41–60 и 61–71. В каждом снимке шрифты и картинки встроены, иконки развёрнуты, а стили SVG перенесены в атрибуты. Каждый файл импортируется в Figma одним вызовом `html_to_figma` (Figma MCP) с `cssSelector: "#deck > .s"`: файл отправляется POST на выданный адрес с `Content-Type: text/html`. Каждый слайд станет фреймом 1600 × 900 из редактируемых слоёв с именем «NN · заголовок», фреймы лягут сеткой в 5 колонок. На тарифе Starter у Figma MCP 20 вызовов чтения в месяц, импорт колоды тратит четыре из них. Почему снимок устроен именно так, сказано в шапке скрипта.

## Правила

- Числа «Моторики» — только из открытых источников: годовые отчёты за 2024 и 2025 годы, IR-брошюра 2025, результаты I полугодия 2026 года, пресса, открытый код. У каждого слайда — строка источников; цитаты — дословно, со страницей. Чего нет в первоисточнике, того нет в колоде: фактчекинг 20.11.2026 убрал неподтверждённые цифры и цитаты.
- Маршрут читателя (`READERS` в `data.mjs`, отметка `ch: 'innov'` у слайдов) — не кресло за столом: `check:motorica` сверяет его слайды на странице, в списке маршрутов и в его PDF. Вопросы маршрута опираются только на публичные публикации и выступления «Моторики» (годовой отчёт 2025, с. 45; интервью департамента нейротехнологий в Наука Mail); цитаты — дословно, с источником в строке слайда; личных сведений о людях в колоде нет — только публичные профессиональные высказывания. id маршрута и адрес `?route=innov` прежние: уже отправленные ссылки и PDF не ломаются.
- Мировая планка и требования 2026 года сверены 23.11.2026: у каждого факта — источник в строке слайда и в `MARKET.md`; нормы — по текстам актов и их разборам, решение по ним — за юристами и регуляторной службой «Моторики».
- Иллюстрации с девушкой — образ амбассадора, а не реальный пользователь; это написано в строке источников каждого такого слайда. Протез на них обезличен: без изделий и логотипа «Моторики».
- Дизайн-слой 2026 (в конце `site.css`): фон раздела — свой арт (Figma, ChatGPT Image 2.5), свечение, сетка точек и зерно; карточки — матовое стекло с бликом по кромке; акценты заголовков и крупные цифры — градиент; столбцы и полосы графиков — градиенты из спрайта (`#g-mint` и другие); иконки кресел — 3D-стекло. В колоде блоки слайда появляются по очереди (без этого — при «уменьшить движение»). В печати (из неё PDF) акценты сплошным цветом, без размытых теней и зерна, а картинки — JPEG-двойники: PDF не знает WebP, и Chrome встроил бы картинку без сжатия.
- На телефоне (лента уже 900 px) широкие схемы — карта компетенций, связи портфеля, шаги WP1, дорожная карта, недели, дерево эффекта, карта рисков, правило решения — не сжимаются до нечитаемого, а листаются вбок в своём блоке (`.hscroll`, его добавляет `app.js`); шаги WP1 там же идут нумерованным списком.
- Типограф (`nb()` в `render.mjs`) обрабатывает все тексты макета, в том числе строки шаблонов: неразрывный пробел ставится перед тире, а не после — строка не начинается с тире; число не отрывается от единицы («4 ставки», «млн ₽»), короткие слова — от следующего, диапазоны «1–3 года» не рвутся на тире.
- Вёрстку каждого слайда проверяет `tools/motorica-layout.mjs` (шаг 5г `check:motorica-page`: печать, колода и лента 390 px): нет обрезанных блоков, текста на тексте и на картинках, подписей за краем и вне своих плашек, слипшихся подписей, линий сквозь буквы, фрагментов не того размера или цвета.
- Слайд «Проверяемость»: что доказано сегодня (цифры «Моторики» — из её документов, наши числа воспроизводятся, тренажёр готов к пилоту, EBITDA без процентов) и что докажет пилот (перенос навыка на протез, допущения модели, статус тренажёра, стыки с закрытым кодом после NDA).
- Модель показывает масштаб эффекта: база 2025 года заморожена, рост рынка, ноги, центры, нейротех и экспорт не учтены. Допущения помечены и проверяются пилотом и данными «Моторики».
- EBITDA модели = (L1 + L2) × маржа 26 % + рычаги затрат L3–L6. L7 — экономия на стоимости денег, то есть проценты: она ниже EBITDA и в итог не входит, а оборотный капитал (≈93 млн ₽ в базовом сценарии) высвобождается разово — в дереве эффекта эта ветвь пунктиром. L1 распределяет выручку замены по годам цикла: по кассе первая замена приходит через 1–3 года после выдачи. `check:motorica` и `motorica-model.py --check` следят, чтобы L7 не вернулся в EBITDA ни на странице, ни в калькуляторе, ни в книге.
- Публичный репозиторий и сайт — без переговорных позиций и цен: смета — после рабочей сессии этапа 0.
- Контакты — только на слайде «Решения» в одном блоке страницы между `contacts:begin` и `contacts:end`; `check:motorica` не пропустит их в другом месте, в том числе в `slides.json`.
- Страница не индексируется (`noindex`), без внешних запросов (CSP `default-src 'self'`), без скрипта показывает слайды лентой, работает офлайн.
- `check:motorica` — слайды на странице = страницы PDF = слайды PPTX = `slides.json`, тот же текст, `?v=`, CSP, alt, якоря, маршруты, план = модель. `check:motorica-page` — колода в Chromium: клавиши, `#sN`, маршруты, заметки, калькулятор = модель, ссылка на расчёт, правило решения, тренажёр, интерактив не двигает вёрстку, 320–2560 px, axe-core — 0 нарушений, офлайн.
