## A. Протокол каждой сессии ИИ

1. **Старт (≤ 5 % бюджета).** Прочитать `MEMORY.md` → этот файл (разделы B и C) → только файлы текущей задачи. Карта слоёв — `docs/ARCHITECTURE.md`. Весь проект **не сканировать**: искать `grep -rn`, читать фрагменты `sed -n 'a,bp'`.
2. **Базовая линия до любых правок** — в корне репозитория:
   ```bash
   npm ci && npm test                       # ожидается: # tests 244, # fail 0 (≈ 5 с); без PNG-иконок падает 1 тест и говорит почему
   python3 -m unittest bridge/test_ws_bridge.py  # ожидается: OK (8 тестов)
   node tools/gesture-drill.mjs             # ожидается: «OK», падает только тест-напоминание о синонимах моста
   node tools/check-submission.mjs --draft  # ожидается: 0 ошибок, 3 предупреждения (AUTHORS, дата первого коммита, отладочная подпись APK)
   ```
   Если базовая линия не совпала — сначала понять почему, записать в `MEMORY.md`, затем работать.
3. **Одна сессия = один сценарий раздела B** (или 2–3 пункта размера S). Порядок — как в B.
4. **Цикл изменения:** тест (или правка теста) → код → `npm test` (включает сборку всего бандла — синтаксис UI) → для UI ещё `npm run build` и e2e (C.1.2) → документы (`SCENARIOS`, `GLOSSARY`, `GAME_DESIGN`/`ARCHITECTURE` при необходимости) → коммит. Числа тестов в документах — `node tools/set-test-count.mjs` (ворота проверят).
5. **Финиш (≤ 10 %):** раздел B.F. Без `npm run pack` сессия не закончена.
6. **Стоп-правило.** Если контекст стал большим (ответы теряют точность, приходится перечитывать уже прочитанное) или две попытки подряд не прошли тесты — остановиться, записать в `MEMORY.md` «что сделано, что сломано, следующий шаг», отметить пункт здесь и продолжить в новой сессии.
7. **Обязательные принципы:** DRY (параметры — `src/config.js`; словарь и набор жестов — `src/core/vocabulary.js`; путаницы — `GESTURE_CONFUSION`; формат кадров — `parseExternal()`; шаг цепочки — `GameRunner`), KISS (ванильный JS, без фреймворков и новых зависимостей в продукте), SOLID (новая игра = файл + строка в `registry.js`; новый источник = `sample(now)` или `BridgeSource.feed`; трекеры и стражи — чистые классы, внедряются параметром), единый язык (`docs/GLOSSARY.md`).
8. **Правило ворот:** каждая новая проверка в `tools/check-submission.mjs` получает случай с подложенной ошибкой в `tests/submission.test.mjs` (иначе проверка может молча не работать — C.1.12).

## C. Опыт прошлых сессий — грабли и как их обходить

### C.1 Технические

1. **Кириллица в регулярках JS:** `\w` совпадает только с ASCII. Использовать `[а-яёa-z]` (см. `tools/check-submission.mjs`, `const W`). Любой новый фильтр проверять на списке «старых плохих» и «допустимых» фраз.
2. **`pkill -f "шаблон"` убивает собственную оболочку**, если шаблон есть в её командной строке. Сервер запускать отдельным вызовом: `nohup python3 tools/serve.py --dist --port 8091 >/dev/null 2>&1 &`; останавливать по PID или `pkill -f "[s]erve.py"`. Скобки не спасают, если в **той же** команде шаблон встречается ещё раз без скобок (например, в `pgrep … serve.py`) — оболочка убьёт себя (exit 144, сессия 5.3.0). `pkill` — отдельным вызовом.
3. **`.gitignore` не убирает уже отслеживаемые файлы.** Из-за этого в 5.1.0 `dist/` был в git, а в архиве его нет, и ворота падали с `ENOENT`. Теперь проверка ловит артефакты сборки в git; архив проверять **только** через `npm run pack` (распакованная копия).
4. **Импорт тестового файла повторно регистрирует его тесты** — общие помощники только в `tests/helpers.mjs`.
5. **Android без SDK:** заглушки в `android/stubs` должны совпадать с платформой побайтно — `VERIFY_API=1` (Robolectric android-all 29, 131 МБ, кэш `tools/.cache`). Новый API: сначала заглушка, потом проверка.
6. **WebView ≠ браузер:** нет Web Speech, blob-загрузок и Web Bluetooth → нативный мост `window.SynergyNative` (`speak/stop/share/print`). Новые возможности закладывать с проверкой `globalThis.SynergyNative?.метод`.
7. **Полностраничные скриншоты Playwright** рисуют липкие панели посреди страницы — это не ошибка вёрстки.
8. **Бот ≠ человек:** автопилот видит задание и не опаздывает. После любой правки баланса запускать модель новичка (`playNovice` в `tests/helpers.mjs`); её допуски закреплены в `tests/human.test.mjs`.
9. **Навыки считаются по исходным допускам уровня,** а очки — по адаптированным; не смешивать, иначе облегчение «раздувает» навык.
10. **Сеть среды:** `WebFetch` блокирует часть доменов (codenrock.com, motorica.org, docs.github.com, rb.ru, tproger.ru) — использовать `WebSearch`; Maven Central и npm доступны.
11. **`npm test` не импортировал UI** — синтаксическая ошибка в `ui/settings.js` прошла 95 тестов. Теперь `tests/bundle.test.mjs` собирает весь бандл (esbuild): синтаксис и несуществующие импорты в любом модуле роняют `npm test`.
12. **Проверка в воротах может молча не работать:** число тестов в README/JURY/MEMORY не сверялось с 5.1.0 — `\b` после кириллицы в JS не срабатывает. Исправлено (`(?![а-яёa-z])`), и введено правило A.8: каждой проверке — случай с подложенной ошибкой в `tests/submission.test.mjs`.
13. **`dt` цикла ограничен 50 мс** (`App.frame`). Всё, что меряет реальное время (частота кадров, задержка), должно брать разницу `now`, иначе на слабом устройстве время «течёт» медленнее в разы (так страж кадров сначала не срабатывал; поймано замедлением CPU через CDP: `Emulation.setCPUThrottlingRate`).
14. **Maven Central отвечает 429** под нагрузкой. `tools/build-apk.sh` повторяет загрузку (`curl --retry`) и сверяет SHA-256 каждой jar; при смене версии инструмента — обновить хэш.
15. **Сеть среды ИИ (17.10):** `WebFetch` и `curl` не открывают frontiersin.org, ncbi.nlm.nih.gov, doaj.org, api.crossref.org, europepmc, api.github.com. Статьи — `WebSearch` (mode extended даёт фрагменты методов); версии GitHub Actions — `git ls-remote --tags https://github.com/actions/X`, дата — `git fetch --depth=1 … refs/tags/vN.0.0` и `git log -1 --format=%cs`.
16. **Ворота проверяют формулировки во всех отслеживаемых файлах, включая тесты:** запрещённую фразу в тесте собирать из частей (`['Перенос', 'на протез', 'доказан.'].join(' ')`).
17. **CSP приложения запрещает инлайн-скрипты:** axe-core внедряется через `page.evaluate(source)` (протокол DevTools), а не `addScriptTag`.

38. **Flex-ловушки (5.8):** `min-height` на flex-элементе отменяет его автоматический минимум — он сжимается меньше содержимого (подсказка наезжала на сигнал) → `flex: none`; `justify-content: flex-end` при переполнении уводит содержимое за верхний край без прокрутки → `margin-top: auto` первому элементу; `align-self` в flex-колонке — по горизонтали.

42. **Контракт входа — явный (5.9, внешний аудит T6):** значение вне контракта (отрицательная «огибающая») не исправлять молча (`Math.abs`), а распознать режим, назвать его в статусе и покрыть тестом (`EnvelopeFilter`, `tests/rawemg.test.mjs`).

44. **Состояние ввода не переживает переход между экранами:** цель эмулятора сбрасывается в `go()` — иначе «залипшая» площадка (режим без удержания) переносит сжатие в следующую игру.
45. **Число — из прогона, не из журнала:** в документы пишем результат проверки с датой и средой (ОС, Playwright, браузер); «0 находок» без прогона в этой версии — цитата, а не факт. Внешний аудит получил 129/130 из-за нераспакованных PNG — тест должен сам сказать причину.
46. **`overflow-wrap: anywhere` прячет дефект:** переполнения нет — и линтер молчит, а на экране «Пропорциональны / й». Проверка `broken` в линтере ищет слова, разорванные посередине; ширину колонок задаёт самое длинное слово (`--word`). Container query меряет **содержимое** без padding и рамки — порог считать от него (иначе площадки жестов складывались и в альбомной вылезали за экран — поймал e2e).
47. **Холст тоже раскладка:** подписи радара обрезались на любом экране с 5.0 — ни линтер, ни axe холст не видят. Геометрию холста выносить в чистую функцию (`radarLayout`, `rhythmLayout`) и проверять тестом, что текст внутри.

80. **Пример кода «проверен» — только инструментом** (5.15): Kotlin — `kotlinc` против android-all 29 (тот же jar, что у `VERIFY_API=1`), React Native — `tsc --strict` против настоящих типов; что не компилировалось (Swift, Flutter, Unity: нет инструментов в среде, download.swift.org и .NET закрыты прокси) — так и пишем. `tsc` нашёл ловушку: в `react-native-webview` 14 `useRef<WebView>` даёт `never`, нужен `WebView<object>`. Повтор: `npm run verify:embed`.
81. **WebSocket в Node 22 настоящий** (5.15): юнит-тест, который включает внешний источник, открывает соединение к адресу по умолчанию; `onerror → close()` в undici вызывал ошибку снова — бесконечная рекурсия после конца теста. В тестах `globalThis.WebSocket = undefined` (как в `app.test.mjs`), в коде — снимать обработчик до `close()`.
82. **`replaceChildren(..., null)` печатает «null»** (5.15): `h()` пропускает пустые дети, DOM — нет. Условные дети вне `h()` — через `fill()` (`ui/primer.js`).
83. **Анимация с `perspective` расширяет страницу** (5.15): линтер поймал переполнение на кадре переворота карточки; движение — без 3D, только сдвиг и прозрачность. И длинное слово при 200 % раздвигает элемент сетки — `min-width: 0` детям сетки и `overflow-wrap: break-word` (не `anywhere`: тот прячет дефект от проверки `broken`).
84. **e2e встраивания — два origin одной машины** (5.15): `127.0.0.1` и `localhost` — разные origin; второй сервер отдаёт страницу хоста. «Дальше» онбординга игнорирует касание первые 300 мс страницы — ждать перед первым щелчком и в `iframe`.
85. **Учебная замена копирует документы, которые читают тесты** (5.15): `docs/*.md` и `docs/embed/` — иначе тест набора встраивания и тест ссылок падают в копии. С 5.16 копирует и `android/` (без `android/build`) для теста иконок; на Windows `node_modules` подключается junction — symlink каталога там требует прав администратора.
86. **Вырезку фона проверять на тёмном фоне, а не на белом** (5.16): на белом любая альфа выглядит правильно. Листы `--sheets` показывают каждую картинку на тёмном и мятном. Так нашлись белые поверхности, потерянные маской, и «пыль» шума сжатия (фон 250–254, а не 255).
87. **Детектору глаз не верить на закрытых глазах** (5.16): открытый клюв темнее век, детектор взял его за глаз (наклон −21°). Глаза радостных и сонных картинок сняты по вырезкам ×2 с сеткой 8 px. После замены картинки птицы — сверить `EYES` в `tools/import-art.py` и лист `outfits.jpg`.
88. **Числа NumPy в сгенерированном JS** (5.16): `round(np.float64)` печатается как `np.float64(12.3)` — модуль не импортируется. В генераторах — `float()`.
89. **PowerShell 5: `Get-Content`/`Set-Content` портят UTF-8** (5.16): без `-Encoding` файл читается как Windows-1251, при записи кириллица превращается в «РЎРёРЅ…». Так испортился `index.html` (e2e не заметили — они открывают `dist/`). Править Node или редактором. Тест «нет двойной перекодировки» ловит такую поломку.
90. **Одна правка на один файл за раз** (5.16): параллельные замены в одном файле могут примениться дважды или не там. После пакета правок — `grep`, что каждая встала один раз.
91. **Переносы по слогам — не разрыв слова** (5.16): на Windows (и Android) Chromium расставляет русские переносы при `hyphens: auto`, линтер считал это разрывом — 176 ложных находок. Теперь он проверяет то же слово с `hyphens: manual`.
92. **BlueStacks на этой машине — Android 7.1.1** (5.16): WebView — Chrome 119, адаптивная иконка там не видна (API < 26). Системный `adb` в `C:\Windows\System32` без своих DLL не запускается — нужен `HD-Adb.exe` из BlueStacks. Касания — `input tap` в пикселях экрана 1600 × 900; Esc в WebView не доходит.
93. **Загрузка второй модели rembg (`u2net`) зависла на нуле байт** (5.16): хватило `isnet-general-use` и заливки замкнутых поверхностей — вторая модель не нужна.
