# Лаборатория ЭМГ

- `signals.py` — DSP-ядро v3 команды: синтетическая 4-канальная сырая sEMG, полосовой фильтр Баттерворта 20–450 Гц, признаки (RMS, MAV, WL, ZC, SSC), LDA (5 классов).
- `lab7.py` — расширение до 7 жестов игры (покой + 6 активных), классификатор `Classifier7`.
- `test_lab7.py` — точность на отложенных синтетических данных (синтетика проще реальной ЭМГ).

```bash
pip install -r lab/requirements.txt
python -m unittest lab/test_lab7.py
python3 bridge/ws_bridge.py --lab      # поток в игру: Настройки → Внешний → ws://127.0.0.1:8765
```
Только синтетические данные; не модель пациента. Что обещает и чего не обещает — [карточка модели](../docs/MODEL_CARD.md).
