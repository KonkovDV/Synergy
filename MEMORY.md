## Ключевые решения (и почему)

| Решение | Почему |
|---|---|
| Модель протеза: скорость ∝ сигналу, хват держится сам, B ослабляет, коактивация меняет хват | перенос навыка требует того же закона управления (Garske 2021, van Dijk 2016) |
| «Испытание без подсказки» в каждом плане дня | игровая метрика удержания по мотивам тренировки с отсроченной обратной связью (Dupan 2025: 12 здоровых участников, перенос на протез после 5 сессий); у нашей игры перенос не проверен |
| Коактивация: оба ≥ 40 % комфортного уровня (≈ 28 % МПС), начала ≤ 350 мс, повтор только после покоя | по мотивам правила Maas 2024 (у них 40 % МПС, пики; та же работа переноса не показала — не цитировать как пользу); защита от случайных переключений |
| 7 жестов = покой + 6 активных (Кулак, Ладонь, Щепоть, Указательный, Ключ, Класс) | Omni Hand распознаёт до 6 «фантомных» жестов; набор в одном файле |
| Ритм-игра с полосами силы | PlayBionic/MyoBeatz: ритм — лучший вызов для ЭМГ |
| Серия с днём отдыха + недельная цель, мягкий лимит 30 мин | мышцам нужен отдых; дни в неделю — цель пользователя (по умолчанию 4), а не назначение; длительность занятия — по образцу игровых протоколов (PlayBionic: 10–15 мин) |
| Управление без касания (удержание A) на старте и итогах | датчики на одной руке, телефон в другой |
| Ванильный JS + Canvas, без движка | офлайн, ~215 КБ JS, мгновенная сборка, headless-тесты |
| Экранный эмулятор с шумом/тремором/помехами/ошибками классификатора | честная проверка без железа; тот же путь сигнала для демо |
