# MEMORY.md — состояние проекта для новой сессии

## Что это

«Синергия» v5.1.0 — мобильная игра-тренажёр управления бионическим протезом по ЭМГ для геймджема «Моторика: Код движения» (ГК «Моторика» + Фонд «Сколково», Codenrock; призовой фонд 1 млн ₽). Команда — SYNERGY. v3 (лабораторный MVP) сохранён в `legacy/v3`.

## Факты о задаче (подтверждено)

- Схемы: две ЭМГ-кнопки (пороговый и пропорциональный режим) и/или 7 жестов (Правила, п. 2.2, 3.4; текст правил — на платформе Codenrock, в репозиторий не включён: объект прав третьего лица).
- 5 критериев, ≤ 90 баллов, публикуются 28.10 (п. 3.7–3.8). ИИ разрешён с раскрытием.
- Продукт: интерфейсы, описание функционала, исходный код, минимальный дизайн; одна команда — один продукт.
- Дедлайн загрузки 11.11 13:00 МСК (рекомендовано до 12:30). Права победителей переходят организатору (п. 6.6).

## Ключевые решения (и почему)

| Решение | Почему |
|---|---|
| Модель протеза: скорость ∝ сигналу, хват держится сам, B ослабляет, коактивация меняет хват | перенос навыка требует того же закона управления (Garske 2021, van Dijk 2016) |
| «Испытание без подсказки» в каждом плане дня | перенос на протез предсказывают попытки без живой обратной связи (Dupan 2025, Stuttaford 2023) |
| Коактивация: оба ≥ 40 %, начала ≤ 350 мс, повтор только после покоя | правило подсчёта из Maas 2024 (та же работа переноса не показала — не цитировать как пользу); защита от случайных переключений |
| 7 жестов = покой + 6 активных (Кулак, Ладонь, Щепоть, Указательный, Ключ, Класс) | Omni Hand распознаёт до 6 «фантомных» жестов; набор в одном файле |
| Ритм-игра с полосами силы | PlayBionic/MyoBeatz: ритм — лучший вызов для ЭМГ |
| Серия с днём отдыха + недельная цель, мягкий лимит 30 мин | мышцам нужен отдых; доза 15 мин × 3–5 дней/нед в исследованиях |
| Управление без касания (удержание A) на старте и итогах | датчики на одной руке, телефон в другой |
| Ванильный JS + Canvas, без движка | офлайн, ~215 КБ JS, мгновенная сборка, headless-тесты |
| Экранный эмулятор с шумом/тремором/помехами/ошибками классификатора | честная проверка без железа; тот же путь сигнала для демо |

## Решения v5 (и почему)

| Решение | Почему |
|---|---|
| Адаптивная сложность ±30 % допуска, цель 75 % | challenge point; навыки «Точность» — по исходным допускам, чтобы облегчение не завышало метрики |
| «Проверка навыка» с фиксированным протоколом | Motion Test / TAC: сравнимость неделя к неделе, пригодна для пилотной валидации |
| Опрос боли/усталости → go/light/stop; день боли не прерывает серию | безопасность > мотивация; этичная геймификация |
| Признаки усталости по падению результата, не по амплитуде ЭМГ | при субмаксимальном усилии амплитуда с усталостью растёт |
| Без открытой лицензии | п. 6.6: открытая лицензия сохранится при отчуждении права (ГК ст. 1235 п. 7) |
| Нативный мост Android (TTS, share, print) | WebView: нет Web Speech и blob-загрузок |
| Заглушки Android сверяются с API 29 (`VERIFY_API=1`) | APK без Android SDK, но без риска NoSuchMethodError |
| Схема хранения осталась `synergy.v4` / version 4 | новые поля добавочные, данные v4 сохраняются |

## Карта кода

`src/config.js` параметры · `src/core/` домен (vocabulary, signal, hand, calibration, progress, storage, rng, adaptive, wellbeing, tutorial, analytics, showcase) · `src/input/` (emulator, bridge, ble, controls) · `src/games/` (base, grip, flight, rhythm, safe, assess, registry, runner) · `src/render/draw.js` · `src/services/` (audio, voice, feedback, report) · `src/ui/` (экраны) · `src/app.js` композиция · `bridge/ws_bridge.py` мост · `lab/` DSP+LDA · `android/` оболочка APK · `tools/` сборка · `tests/` тесты · `docs/` документы.

## Команды

```bash
npm install                      # esbuild (только для сборки)
npm test                         # 70 тестов: ядро, v5-модули, игры × уровни × схемы, модель новичка
npm run check:submission         # документы = продукт; авторы, версии, ключи, лицензия
python3 tools/serve.py --dist --port 8091 & node tests/e2e/v5.mjs   # e2e v5 + скриншоты docs/screenshots/v5-*
VERIFY_API=1 sh tools/build-apk.sh  # APK + сверка заглушек с Android API 29
npm run build                    # dist/ (PWA) + dist/synergy-standalone.html
python3 tools/serve.py           # дев-сервер http://127.0.0.1:8080 (исходники, ES-модули)
python3 tools/serve.py --dist --lan  # собранная версия для телефона в той же Wi-Fi
npm run e2e                      # Playwright, нужен сервер на :8090 (python3 tools/serve.py --port 8090)
node tests/e2e/bridge.mjs <url> ws://127.0.0.1:8766 ws://127.0.0.1:8767   # с запущенными мостами --demo и --lab
sh tools/build-apk.sh            # android/build/synergy.apk (JDK + Node + интернет к Maven Central)
python3 bridge/ws_bridge.py --demo | --demo-gestures | --stdin | --lab
```
