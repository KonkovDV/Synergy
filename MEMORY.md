## Сейчас

График в «Чувствительности» считает рабочим более сильный канал: задания там нет. Дальше: первый зелёный прогон CI, скринкаст, **28.10 после 18:00 — день опубликованной задачи** (список материалов откроется после церемонии). ## Ключевые решения (и почему)

| Решение | Почему |
|---|---|
| Модель протеза: скорость ∝ сигналу, хват держится сам, B ослабляет; с 5.23 хват меняется, как у протеза «Моторики» — снова B у раскрытой кисти (коактивация там — блокировка), коактивацией — по настройке | перенос показан только у тренажёров с задачей протеза, у абстрактных игр не показан (Garske 2021 — статья-мнение, 5.27); van Dijk 2016 |
| «Испытание без подсказки» в каждом плане дня | игровая метрика удержания по мотивам тренировки с отсроченной обратной связью (Dupan 2025: 12 здоровых участников, перенос на протез после 5 сессий); у нашей игры перенос не проверен |
| Коактивация: оба ≥ 40 % комфортного уровня (≈ 28 % МПС), начала ≤ 350 мс, повтор только после покоя | по мотивам правила Maas 2024 (у них 40 % МПС, пики; та же работа переноса не показала — не цитировать как пользу); защита от случайных переключений |
| 7 жестов = покой + 6 активных (Кулак, Ладонь, Щепоть, Указательный, Ключ, Класс) | Omni Hand распознаёт до 6 «фантомных» жестов; набор в одном файле |
| Ритм-игра с полосами силы | PlayBionic/MyoBeatz: ритм — лучший вызов для ЭМГ |
| Серия с днём отдыха + недельная цель, мягкий лимит 30 мин | мышцам нужен отдых; дни в неделю — цель пользователя (по умолчанию 4), а не назначение; длительность — 5–10 минут активной игры, ориентир «Моторики» с митапа (`SESSION.activeMin`; у PlayBionic было 10–15 мин) |
| Управление без касания (удержание A) на старте и итогах | датчики на одной руке, телефон в другой |
| Ванильный JS + Canvas, без движка | офлайн, ~215 КБ JS, мгновенная сборка, headless-тесты |
| Экранный эмулятор с шумом/тремором/помехами/ошибками классификатора | честная проверка без железа; тот же путь сигнала для демо |

## Решения v5.3 (и почему)

| Решение | Почему |
|---|---|
| Набор жестов — только `vocabulary.js`; производные `ACTIVE/CLOSING/OPENING`, `COMMAND_POSE`, `GRIP_NAME`, `gestureLegend()`; поля `introducedAt`, `cue` | день публикации задачи: замена = правка одного файла; проверено учебной заменой и статическим тестом |
| Мост принимает id, русские имена (без регистра), индекс класса (`CLASS_ORDER`), синонимы | меньше правок адаптера 28.10; синонимы — только в `GESTURE_ALIASES` |
| Подстройка покоя: модель смещения (покой и максимум сдвигаются вместе), τ 60 с, только в подтверждённом покое ≥ 1 с, сдвиг ≤ 20 % диапазона | дрейф базовой линии аддитивный (пот, импеданс); ограничение не даёт «подстроиться» под ошибку |
| Резкий скачок покоя ловится как «канал включён > 15 с», а не через трекер | **отступление от плана B.3:** при скачке на 40 % сигнал никогда не выглядит как покой, трекер его не увидит; ни одна игра не требует 15 с непрерывного сжатия |
| Подстройки нет в «Проверке навыка», демо и экранном эмуляторе | сравнимость недель; эмулятор уже нормирован |
| Фиттс: только пропорциональная схема, номинальная ширина W, удержание 0,5 с, MT до входа в окно без удержания, TP — среднее ID/MT | по мотивам тестов миоуправления (Kamavuako 2014, Gusman 2017); номинальная W, а не эффективная We из ISO 9241-411 — поэтому «игровая пропускная способность»; старые 6 градуированных попыток стали блоком Фиттса — длительность проверки не выросла |
| Бот ~13,6 бит/с, новичок ~4,5 — тест проверяет порядок, а не диапазон плана [0,5; 8] | бот движется мгновенно — это верхняя граница, не человек |
| Путаницы жестов — веса пар в `GESTURE_CONFUSION`, частота × (1,5 − усилие) | открытые наборы: похожие хваты путаются чаще; общая таблица для эмулятора и демо-профиля |
| Страж кадров на уровне `App` (на визит), по реальному времени кадра, паузы > 0,5 с не считаются | один тост; `dt` цикла ограничен 50 мс и врёт на слабом устройстве |
| axe-core в e2e: ноль нарушений любой серьёзности (WCAG 2.2 A/AA + best practices) | строже плана (там serious/critical), т. к. база уже нулевая — регрессии видны сразу |
| Actions — актуальные мажоры (выпущены > 2 недель назад), закреплены по SHA; аттестация только для публичного репозитория | OpenSSF Scorecard; для приватного репозитория аттестация требует GitHub Enterprise Cloud |
