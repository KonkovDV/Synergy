# MEMORY.md — состояние проекта для новой сессии

## Что это

«Синергия» v4.0.0 — мобильная игра-тренажёр управления бионическим протезом по ЭМГ для геймджема «Моторика: Код движения» (ГК «Моторика» + Фонд «Сколково», Codenrock; призовой фонд 1 млн ₽). Команда — SYNERGY. v3 (лабораторный MVP) сохранён в `legacy/v3`.

## Факты о задаче (подтверждено)

- Схемы: две ЭМГ-кнопки (пороговый и пропорциональный режим) и/или 7 жестов (`customer/rules.txt`, п. 2.2, 3.4).
- 5 критериев, ≤ 90 баллов, публикуются 28.10 (п. 3.7–3.8). ИИ разрешён с раскрытием.
- Продукт: интерфейсы, описание функционала, исходный код, минимальный дизайн; одна команда — один продукт.
- Дедлайн загрузки 11.11 13:00 МСК (рекомендовано до 12:30). Права победителей переходят организатору (п. 6.6).

## Ключевые решения (и почему)

| Решение | Почему |
|---|---|
| Модель протеза: скорость ∝ сигналу, хват держится сам, B ослабляет, коактивация меняет хват | перенос навыка требует того же закона управления (Garske 2021, van Dijk 2016) |
| «Испытание без подсказки» в каждом плане дня | перенос на протез предсказывают попытки без живой обратной связи (Dupan 2025, Stuttaford 2023) |
| Коактивация: оба ≥ 40 %, начала ≤ 350 мс, повтор только после покоя | параметры из Maas 2024; защита от случайных переключений |
| 7 жестов = покой + 6 активных (Кулак, Ладонь, Щепоть, Указательный, Ключ, Класс) | Omni Hand распознаёт до 6 «фантомных» жестов; набор в одном файле |
| Ритм-игра с полосами силы | PlayBionic/MyoBeatz: ритм — лучший вызов для ЭМГ |
| Серия с днём отдыха + недельная цель, мягкий лимит 30 мин | мышцам нужен отдых; доза 15 мин × 3–5 дней/нед в исследованиях |
| Управление без касания (удержание A) на старте и итогах | датчики на одной руке, телефон в другой |
| Ванильный JS + Canvas, без движка | офлайн, 150 КБ, мгновенная сборка, headless-тесты |
| Экранный эмулятор с шумом/тремором/помехами/ошибками классификатора | честная проверка без железа; тот же путь сигнала для демо |

## Карта кода

`src/config.js` параметры · `src/core/` домен (vocabulary, signal, hand, calibration, progress, storage, rng) · `src/input/` (emulator, bridge, controls) · `src/games/` (base, grip, flight, rhythm, safe, registry, runner) · `src/render/draw.js` · `src/services/` (audio, feedback, report) · `src/ui/` (экраны) · `src/app.js` композиция · `bridge/ws_bridge.py` мост · `lab/` DSP+LDA · `android/` оболочка APK · `tools/` сборка · `tests/` тесты · `docs/` документы.

## Команды

```bash
npm install                      # esbuild (только для сборки)
npm test                         # 41 тест: ядро + все игры × уровни × схемы
npm run build                    # dist/ (PWA) + dist/synergy-standalone.html
python3 tools/serve.py           # дев-сервер http://127.0.0.1:8080 (исходники, ES-модули)
python3 tools/serve.py --dist --lan  # собранная версия для телефона в той же Wi-Fi
npm run e2e                      # Playwright, нужен сервер на :8090 (python3 tools/serve.py --port 8090)
node tests/e2e/bridge.mjs <url> ws://127.0.0.1:8766 ws://127.0.0.1:8767   # с запущенными мостами --demo и --lab
sh tools/build-apk.sh            # android/build/synergy.apk (JDK + Node + интернет к Maven Central)
python3 bridge/ws_bridge.py --demo | --demo-gestures | --stdin | --lab
```
