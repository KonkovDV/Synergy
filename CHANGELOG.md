# Журнал изменений

## 5.2.0 — 17.10.2026
- **Затухающая обратная связь** (guidance hypothesis): навык < 60 — шкала в каждой попытке, 60–79 — в 2 из 3, ≥ 80 — в 1 из 2; результат скрытой попытки показывается сразу после неё. «Мастерская» (шкала силы), «Сейф» (круг удержания), «Ритм» (шкала силы по тактам). Переключатель в Настройки → Тренировка.
- **Интервальное повторение в плане дня**: игра, которой не было d дней, получает приоритет min(d, 7) × 3 очка — каждый навык возвращается в течение недели.

## 5.1.0 — 17.10.2026 (разбор «как жюри»)
- **Модель новичка** в тестах (реакция 250 мс, шум силы ±12 %, провалы внимания, шумный датчик): нашла непроходимость пороговой схемы → рост силы в «Мастерской» 0,55 → 0,35/с, набор высоты в «Полёте» 0,32 → 0,53/с по уровням; уровень 1 проходим во всех схемах, кривая сложности растёт.
- **`npm run check:submission`**: версии, цифры в README/JURY/MEMORY = реальность (тесты, размер APK), `AUTHORS.md`, лицензия, ключи, текст правил; в CI — режим `--draft`.
- **PIN**: 4–6 цифр, блокировка после 5 ошибок (30 с → 15 мин).
- **Подпись**: отладочный ключ удалён из репозитория и истории; релиз только своим ключом (секреты CI), локально — временный ключ в кэше с предупреждением.
- **Честность**: формулировки о науке без завышения (игровая метрика, а не прогноз; Maas 2024 — правило подсчёта; 44 % — австрийская выборка); `docs/TASK.md` — цитаты правил и хронология; `JURY_STRATEGY.md` переписан под v5.
- Предупреждения при открытии сервера и моста в сеть.

## 5.0.0 — 17.10.2026
- **Проверка навыка** — еженедельный стандартный тест по мотивам Motion Test / TAC: доля выполненных, время выбора, время выполнения, точность, перелёты.
- **Адаптивная сложность** внутри упражнения (challenge point ≈ 75 % успеха); без подстройки в испытании без подсказки и проверке.
- **Самочувствие**: боль (шкала NRS) и усталость перед планом → обычная / лёгкая тренировка / отдых; «насколько тяжело» после; признаки усталости по падению результата; день отдыха по боли не прерывает серию.
- **Первые шаги** — интерактивное обучение с живой кистью.
- **Доступность**: озвучивание (Web Speech / нативный TTS), текст 115/130 %, высокий контраст, «меньше движения», темп игр, время удержания, вибро-метроном.
- **Детский режим** с PIN родителя; **демо-профиль** для презентации.
- **Отчёт для специалиста**: печать/PDF, проверки навыка, ошибки жестов, самочувствие; резервная копия и восстановление.
- **Bluetooth-датчики** (Nordic UART) + прошивка-пример ESP32; Android: TTS, «Поделиться», печать в PDF, усиленная безопасность WebView.
- Дизайн «Aurora»: бенто-сетка, градиентные кнопки, плавающая навигация.
- Исправлено: «Плавность» в «Мастерской» и «Полёте» занижалась (общее среднее между предметами); в APK не сохранялись отчёты.
