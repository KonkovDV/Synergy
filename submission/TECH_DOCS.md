# «Синергия» — техническая документация

Игра-тренажёр управления бионическим протезом кисти по ЭМГ. Версия 6.3.3. Геймджем «Моторика: Код движения», задание 28.10.2026. Готовая игра для Android, iPhone и браузера; тренажёр, не медицинское изделие.

Этот документ собран из репозитория командой `python3 tools/build-docs.py`. Первые разделы — как установить, запустить и проверить. Дальше идут разделы документов репозитория: архитектура (`docs/ARCHITECTURE.md`), интеграция (`docs/INTEGRATION.md`), соответствие ТЗ (`docs/TZ_COMPLIANCE.md`) и границы проекта (`README.md`, полный реестр — `LIMITS.md`). Числа прогонов этой сборки — `docs/evidence.json`.

**Содержание:** 1. Состав решения · 2. Установка и запуск · 3. Первый запуск и использование · 4. Проверка · 5. Архитектура · 6. Интеграция с приложением протеза · 7. Соответствие ТЗ · 8. Границы проекта.

## 1. Состав решения

| Что | Где в репозитории |
|---|---|
| Устанавливаемая сборка Android (APK, Android 5.0+) | `release/Synergy-6.3.3.apk` |
| Та же игра одним файлом для компьютера (офлайн) | `release/synergy-standalone.html` |
| Приложение iPhone и iPad (SwiftUI + WKWebView, сборка на Mac) | `ios/`, инструкция — `ios/README.md` |
| Исходный код игры (JavaScript, модули ES, без фреймворков) | `src/` |
| Эмулятор ЭМГ (Поток 1) — площадки A/B на экране и клавиатура | `src/input/emulator.js`, `src/ui/controls.js` |
| Эмулятор СПППР (Поток 2) — пакеты JSON по ТЗ с джиттером, потерями и ошибками | `src/input/spppr-emulator.js`, программа `tools/spppr-emulator.mjs` |
| Мост для внешнего эмулятора, датчиков и протеза (Python 3.9+, без зависимостей) | `bridge/ws_bridge.py` |
| Тесты (node:test) и браузерные проверки (Playwright, axe-core) | `tests/`, `tests/e2e/` |
| Сборка, ворота сдачи, скринкаст, эта документация | `tools/` |
| Документы | `README.md`, `docs/`, `LIMITS.md`, `CHANGELOG.md` |

Управление — только два канала ЭМГ (Поток 1: пороговый и пропорциональный режимы) или поток СПППР (Поток 2: семь состояний или «2 жеста + нейтраль» с любой парой жестов). Касания нужны только эмулятору на экране и меню; в играх касаний, свайпов и акселерометра нет. Есть режим «без касания»: меню подтверждается удержанием канала A.

## 2. Установка и запуск

### Android

1. В репозитории откройте `release/` и скачайте `Synergy-6.3.3.apk` на телефон (или передайте по USB или в мессенджере).
2. Откройте файл. Android попросит разрешить установку из этого источника — разрешите.
3. «Установить» → «Открыть». Интернет не нужен. Разрешения: вибрация и сеть (сеть — только для внешнего эмулятора или датчиков по WebSocket).
4. Если Android пишет «Приложение не установлено», на телефоне уже стоит «Синергия» с другой подписью (сборки подписаны отладочным ключом машины, где их собрали). Сохраните копию прогресса («Настройки» → «Данные» → «Сохранить копию»), удалите прежнюю версию и поставьте эту.
5. С компьютера: `adb install -r release/Synergy-6.3.3.apk`.

### Компьютер (Windows, macOS, Linux)

Откройте `release/synergy-standalone.html` в Chrome, Edge, Firefox или Safari — один файл, без интернета и установки. Клавиатура: F — канал A (сжатие), J — канал B (раскрытие), пробел — A+B, цифры 1–7 — жесты.

### iPhone и iPad

Исходники — `ios/` (Mac с Xcode 16+ и XcodeGen, `ios/README.md`). Без Mac — та же игра в Safari: «Поделиться» → «На экран „Домой“».

### Из исходного кода

Нужен Node.js 22 или новее.

```bash
npm ci
```

```bash
npm start
```

Откройте http://127.0.0.1:8080 — игра из исходников без сборки. Сборка офлайн-версии (PWA и один HTML-файл) и APK:

```bash
npm run build
```

```bash
VERIFY_API=1 sh tools/build-apk.sh
```

APK собирается без Android Studio и Android SDK: aapt2 и dx скачиваются с Maven Central по SHA-256, Java-код сверяется с настоящим API 29. Результат — `release/Synergy-<версия>.apk` и `release/synergy-standalone.html`.

## 3. Первый запуск и использование

1. **Знакомство.** «Дальше» → «Дальше» (правила безопасности) → «Первые шаги» (обучение, 2 минуты) или «Пропустить обучение». В анкете — схема управления (по умолчанию пороговая, как у серийных протезов), рука с протезом, кто занимается (взрослый или ребёнок с родителем), как отмечать прогресс (Жар-птица или «Только цифры»).
2. **Без датчиков.** Внизу экрана игры — эмулятор ЭМГ: площадка A — сжатие (сгибатели), B — раскрытие (разгибатели), высота пальца — сила, обе площадки — коактивация. В режиме жестов — клавиши семи состояний СПППР.
3. **План дня.** «Главная» → «Тренировка дня» (5–10 минут): упражнения по самым слабым навыкам, отдых между ними, итоги с навыками и командами каждого канала.
4. **Игры.** «Мастерская» (взять, перенести, отпустить с нужной силой; смена хвата), «Полёт» (высота = сила сигнала), «Ритм» (сжатие и раскрытие в такт), «Сейф» (код из команд), «Две руки» (два протеза), «Созвездие» (джойстик СПППР), «Проверка навыка» (раз в неделю, без подсказок). У «Мастерской» 10 уровней, у «Полёта», «Ритма» и «Сейфа» — по 8.
5. **Поток СПППР.** «Настройки» → «Управление» → «Жесты»: набор «СПППР (ТЗ)» (семь состояний) или «СПППР · 2 жеста» — с выбором «Жеста закрытия» и «Жеста раскрытия». Частота эмулятора — 10 Гц (как у СПППР организаторов) или 50 Гц.
6. **Пороги и чувствительность.** «Настройки» → «Чувствительность»: свой порог у каждого канала, калибровка покоя и усилия, живой график A и B.
7. **Специалисту.** «Прогресс»: неделя к неделе, профиль навыков, отчёт для печати, PDF, CSV и JSON. Данные хранятся только на устройстве.
8. **Демо.** «Настройки» → «Данные» → «Демо-профиль для презентации»: заполненный прогресс без своих данных. Кнопка «Смотреть демо» в любой игре: автопилот нажимает площадки эмулятора — видно, когда сжимать и раскрывать.

## 4. Проверка

```bash
npm test
```

Модульные тесты: ядро сигнала, модель кисти, декодер СПППР, все уровни игр автопилотом и моделью новичка, тексты, ворота сдачи.

```bash
npm run test:tz
```

Поток СПППР по ТЗ: все уровни четырёх игр в трёх схемах на потоке 10 и 50 Гц с джиттером и потерями, на обоих словарях и на паре пронация/супинация.

```bash
npm run e2e:a11y
```

```bash
npm run audit:layout
```

Браузерные проверки: экраны без ошибок JavaScript, axe-core (WCAG 2.2 A/AA) без нарушений, линтер раскладки на восьми размерах экрана и трёх размерах текста.

```bash
node tools/check-submission.mjs --draft
```

Ворота сдачи: версии, числа в документах, тексты без преувеличений, APK этой версии в `release/`.

Результаты последнего прогона — `docs/evidence.json` и таблица «Главное» в `README.md`.
