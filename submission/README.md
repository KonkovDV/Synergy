# Что открыть жюри

Репозиторий: https://github.com/KonkovDV/Synergy. Это прототип геймджема «Моторика: Код движения», не медицинское изделие.

## За три минуты

1. Файл `release/synergy-standalone.html` — один файл, интернет не нужен. Его собирает `tools/build-apk.sh`; в git бинарников нет.
2. Android: `release/Synergy-5.31.0.apk`. Сборка подписана отладочным ключом машины, на которой её собрали.
2а. iPhone и iPad: `ios/` — сборка на Mac (`ios/README.md`), без Mac — PWA из Safari. Компьютер: тот же HTML в браузере Windows или macOS.
3. В приложении: «Дальше» → «Дальше» → «Пропустить обучение» → «Настройки» → «Данные» → «Демо-профиль для презентации». Затем «Мастерская».
4. Цифры README пересчитываются так: `npm ci && npm test && npm run check:submission -- --draft`.

## Пакет по слайду 13 митапа

- **Игровой контент.** 5 игр и обучающий режим («Первые шаги», «Азбука протеза»). У «Мастерской» 10 уровней (9 и 10 — кубики и кольца), у остальных игр — по 8.
- **Мобильная версия.** Android: APK из пункта 2. iPhone и iPad: исходники `ios/` и сборка в `ios/README.md`. Без Mac — та же игра из Safari.
- **Техническая готовность.** Цифры прогонов — `docs/evidence.json`.
- **Передача проекта.** Исходный код — этот репозиторий. Запуск — `README.md`. Архитектура — `docs/ARCHITECTURE.md`.

Проверяющему: установить APK → открыть → «Демо-профиль для презентации» (пункт 3) → «Мастерская». Это «Сыграть без датчиков».

## Одна загрузка (11.11)

Дедлайн на платформе — **11.11.2026, 13:00 МСК**. Сдаём не позже **12:30**, лучше утром. Попытка, судя по `submissionAttempts: 1`, одна: второй раз тот же архив не отправляем, пока организатор не скажет иначе.

1. **10.11 вечером** — заморозка кода. После этого только то, без чего ворота не проходят.
2. Утром 11.11: `npm test`, затем `node tools/check-submission.mjs` без `--draft`.
3. `npm run pack`. В архиве нет `*.pptx`, `*.mp4` и файлов больше 10 МБ. Распакованная копия проходит те же ворота.
4. Поставить APK на телефон и открыть `release/synergy-standalone.html` в браузере.
5. В `MEMORY.md` записать ссылку на репозиторий и хэш коммита, который ушёл в загрузку.
