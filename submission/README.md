# Что открыть жюри

Репозиторий: https://github.com/KonkovDV/Synergy. Это прототип геймджема «Моторика: Код движения», не медицинское изделие.

## За три минуты

1. Файл `release/synergy-standalone.html` — один файл, интернет не нужен. Его собирает `tools/build-apk.sh`; в git бинарников нет.
2. Android: `release/Synergy-5.26.0.apk`. Сборка подписана отладочным ключом машины, на которой её собрали.
3. В приложении: «Дальше» → «Дальше» → «Пропустить обучение» → «Настройки» → «Данные» → «Демо-профиль для презентации». Затем «Мастерская».
4. Цифры README пересчитываются так: `npm ci && npm test && npm run check:submission -- --draft`.
