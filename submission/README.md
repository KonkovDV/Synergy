## Посмотреть за три минуты

1. Установите APK и откройте игру: «Дальше» → «Дальше» → «Пропустить обучение».
2. «Настройки» → «Данные» → «Демо-профиль для презентации». Профиль заполнен прогрессом и не трогает ваши данные.
3. «Главная» → «Мастерская» → «Старт». Это «Сыграть без датчиков»: внизу экрана площадки эмулятора, A сжимает кисть, B раскрывает.

Как запустить из исходников — `README.md`. Как устроена игра — `docs/ARCHITECTURE.md`. Где в коде каждое требование задания — `docs/TZ_COMPLIANCE.md`.

## Игровой контент

6 игр и обучающий режим. «Мастерская», «Полёт», «Ритм» и «Сейф» входят в план дня, «Созвездие» тренирует жесты СПППР, «Две руки» — для двух протезов. «Первые шаги» учат управлению с нуля, «Азбука протеза» — короткие карточки о жизни с протезом, «Проверка навыка» раз в неделю показывает прогресс.
