# Что открыть жюри

«Синергия» — игра-тренажёр управления бионическим протезом для геймджема «Моторика: Код движения». Репозиторий: https://github.com/KonkovDV/Synergy. Это обучающий тренажёр, а не медицинское изделие.

## За три минуты

1. **Android:** `release/Synergy-6.3.0.apk` — устанавливаемая сборка. Бинарники в git не хранятся, их собирает `tools/build-apk.sh`.
2. **iPhone и iPad:** `ios/` — сборка на Mac (`ios/README.md`).
3. **Компьютер:** `release/synergy-standalone.html` — та же программа, что внутри APK, одним файлом и без интернета.
4. **В приложении:** «Дальше» → «Дальше» → «Пропустить обучение» → «Настройки» → «Данные» → «Демо-профиль для презентации». Затем «Мастерская» — игра без датчиков.
5. **Цифры README** пересчитываются одной командой: `npm ci && npm test && npm run check:submission -- --draft`.

## Пакет по слайду 13 митапа

- **Игровой контент.** 6 игр и обучающий режим («Первые шаги», «Азбука протеза»). Четыре игры входят в план дня, «Две руки» — для двух протезов, «Созвездие» — для режима жестов набора ТЗ. У «Мастерской» 10 уровней, у остальных игр — по 8.
- **Мобильная версия.** Android — APK из пункта 1. iPhone и iPad — исходники `ios/` и сборка по `ios/README.md`, без Mac — та же игра из Safari.
- **Техническая готовность.** Прогоны и их цифры — `docs/evidence.json`, таблица «Главное» в `README.md`.
- **Передача проекта.** Исходный код — этот репозиторий, запуск — `README.md`, архитектура — `docs/ARCHITECTURE.md`, передача дел — `docs/HANDOFF.md`.

## Загрузка 11.11

Дедлайн на платформе — **11.11.2026, 13:00 МСК**. Отправляем не позже **12:30**, лучше утром: письменные ответы организаторов просят запас в 30 минут. До дедлайна загруженное решение можно заменить — эксперты смотрят последнюю версию. В каждом разделе своя кнопка «Отправить», зелёный значок глаза значит, что материалы на платформе.

1. **10.11 вечером** — заморозка кода. После неё — только то, без чего не проходят ворота.
2. **Утром 11.11** — `npm test`, затем `node tools/check-submission.mjs` без `--draft`.
3. `npm run pack`: в архиве нет `*.pptx`, `*.mp4` и файлов больше 10 МБ, а распакованная копия проходит те же ворота.
4. APK — на телефон, HTML — на компьютер рядом с ним.
5. «Отправить» в каждом разделе, значок глаза — зелёный.
6. Ссылку на репозиторий и хэш отправленного коммита — в `MEMORY.md`.

Решение загружается в GitLab-репозиторий команды (ссылка — в панели участника) зеркалом ветки `main`:

```bash
git remote add gitlab <адрес репозитория команды в GitLab>
```

```bash
git push gitlab main
```

Последний `git push` в GitLab — не позже 11.11, 12:30 МСК: изменения после дедлайна не учитываются.
