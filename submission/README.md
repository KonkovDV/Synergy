# Что открыть жюри

Репозиторий: https://github.com/KonkovDV/Synergy. Это прототип геймджема «Моторика: Код движения», не медицинское изделие.

## За три минуты

1. Android: `release/Synergy-6.3.0.apk` — устанавливаемая сборка. Подписана отладочным ключом машины, на которой её собрали. В git бинарников нет: их собирает `tools/build-apk.sh`.
2. iPhone и iPad: `ios/` — сборка на Mac (`ios/README.md`).
3. Компьютер: `release/synergy-standalone.html` — та же игра одним файлом, интернет не нужен. Это проверка на столе, та же программа, что внутри APK.
4. В приложении: «Дальше» → «Дальше» → «Пропустить обучение» → «Настройки» → «Данные» → «Демо-профиль для презентации». Затем «Мастерская».
5. Цифры README пересчитываются так: `npm ci && npm test && npm run check:submission -- --draft`.

## Пакет по слайду 13 митапа

- **Игровой контент.** 6 игр и обучающий режим («Первые шаги», «Азбука протеза»): четыре в плане дня, «Две руки» — для двух протезов, «Созвездие» — в режиме жестов набора ТЗ. У «Мастерской» 10 уровней (9 и 10 — кубики и кольца), у остальных игр — по 8.
- **Мобильная версия.** Android: APK из пункта 1. iPhone и iPad: исходники `ios/` и сборка в `ios/README.md`. Без Mac — та же игра из Safari.
- **Техническая готовность.** Цифры прогонов — `docs/evidence.json`.
- **Передача проекта.** Исходный код — этот репозиторий. Запуск — `README.md`. Архитектура — `docs/ARCHITECTURE.md`.

Проверяющему: установить APK → открыть → «Демо-профиль для презентации» (пункт 4) → «Мастерская». Это «Сыграть без датчиков».

## Загрузка (11.11)

Дедлайн на платформе — **11.11.2026, 13:00 МСК**. Отправляем не позже **12:30**, лучше утром: письменные ответы просят не позже чем за 30 минут.

Состав решения ТЗ назвало 28.10 (раздел ниже): устанавливаемая сборка, исходный код с эмулятором, скринкаст с комментариями, техническая документация и отчёт о верификации ИИ-фич. Презентация до 15 слайдов — `python tools/build-deck.py` (10 слайдов, файл в git не хранится). Скринкаст собирает `npm run screencast`, в репозиторий его не кладём.

Пока дедлайн не прошёл, загруженное решение можно заменить: эксперты смотрят последнюю версию. В каждом разделе своя кнопка «Отправить». Зелёный значок глаза — материалы на платформе.

1. **10.11 вечером** — заморозка кода. После этого только то, без чего ворота не проходят.
2. Утром 11.11: `npm test`, затем `node tools/check-submission.mjs` без `--draft`.
3. `npm run pack`. В архиве нет `*.pptx`, `*.mp4` и файлов больше 10 МБ. Распакованная копия проходит те же ворота.
4. Поставить APK на телефон. HTML на компьютере — та же игра для проверки рядом с телефоном.
5. Нажать «Отправить» в каждом разделе и проверить, что значок глаза зелёный.
6. В `MEMORY.md` записать ссылку на репозиторий и хэш коммита, который ушёл в загрузку.

## ТЗ 28.10: состав решения и сдача в GitLab

| Что требует ТЗ | Где |
|---|---|
| Готовое приложение или сборка | `release/Synergy-6.3.0.apk` (собирает `sh tools/build-apk.sh`), `release/synergy-standalone.html`, `ios/` |
| Скринкаст с комментариями | `npm run screencast` — ролик ≈ 100 с из этой сборки: подпись к каждой сцене по критериям ТЗ, H.264 1920 × 1080, субтитры `.srt` и главы (`tools/.cache/screencast/`). Голос — по желанию команды. В репозиторий видео не кладём |
| Техническая документация | `README.md`, `docs/ARCHITECTURE.md`, `docs/INTEGRATION.md`, `docs/TZ_COMPLIANCE.md` |
| Отчёт о верификации ИИ-фич | `docs/AI_USAGE.md` (перечень, план, отчёт), планы работ — `docs/PROMPT_TZ.md`, `docs/PROMPT_10HZ.md` |
| Исходный код с эмулятором | весь репозиторий; эмуляторы — `src/input/emulator.js`, `src/input/spppr-emulator.js`, `tools/spppr-emulator.mjs`, `bridge/` |

Решение загружается в GitLab-репозиторий команды (ссылка — в панели участника). Зеркало ветки `main` из этого репозитория:

```bash
git remote add gitlab <адрес репозитория команды в GitLab>
git push gitlab main
```

Изменения после дедлайна не учитываются: последний `git push` в GitLab — не позже 11.11, 12:30 МСК.
