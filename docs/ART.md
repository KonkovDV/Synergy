# Иллюстрации «Синергии» — каталог, места, замена (5.16)

Картинки команды лежат в `public/art/` (WebP), их каталог — `public/art/manifest.json` и сгенерированный `src/ui/art-manifest.js`. Делает их `tools/import-art.py` из пакета 144 PNG (промпты — `docs/DESIGN.md` §6, генерация — `docs/AI_USAGE.md`). Обычной сборке инструменты для картинок не нужны: в репозитории лежат готовые файлы.

## Правило одно для всех экранов

Каждая картинка декоративна (`alt=""`, `aria-hidden`): смысл несут слова рядом. Если картинки нет в каталоге или она не загрузилась, на её месте рисуется SVG 5.12 из `src/ui/art.js`, поэтому битой картинки нет ни на одном экране. Для кистей жестов запасной вариант — кисть, нарисованная на холсте: набор жестов может смениться 28.10, а новый жест без картинки работает как раньше.

## Как вырезан фон

Картинки нарисованы на белом. Тем, что стоят на карточках, нужна альфа, иначе в тёмной теме вокруг них белый квадрат.
1. **Маска объекта** — нейросеть rembg `isnet-general-use`. Она держит непрозрачными белые части самого объекта: корпус Мио, яйцо, белую кисть.
2. **Замкнутые белые поверхности**, которые маска теряет (облачко вопроса, лист отчёта, динамик, циферблат), заливаются, если в них есть светотень: средняя «темнота» больше 4 уровней. Плоский просвет фона (внутри пустой звезды, ручка фонаря) остаётся прозрачным.
3. **Вне маски** белый фон делится по формуле colour-to-alpha: тени, свечение и искры остаются полупрозрачным цветом. Белая точка берётся по краю кадра (у части исходников фон 250–254, а не 255), шум сжатия до 6 уровней — фон.
4. Уменьшение — в предумноженной альфе (без тёмной каймы), WebP с альфой 90.

**Сцены не вырезаются.** «Дело дня», обложки и фоны остаются на своём светлом фоне: белая бумага, полотенце и стеклянная бутылка на вырезке исчезли бы.

## Что носит Жар-птица

Вещи — отдельные картинки поверх птицы. Их рамки (центр, ширина, поворот в процентах кадра) инструмент считает для каждой из 18 картинок с птенцом и старше, от линии глаз:
- голова — 1,05 расстояния между глазами вверх по наклону головы;
- лоб — 0,5;
- грудь — 1,55 вниз.

Глаза сняты по крупным вырезкам с сеткой. На картинках с открытыми глазами их подтверждает детектор тёмных пятен (с точностью до 3 px). Гнездо стоит за птицей у земли: у прыгающей птицы земля — это её тень. Яйцо ничего не носит на голове, птенец — на груди (`core/pet.js`, слоты по стадии).

Поза, которая закрывает слот, уступает картинке настроения, если в этом слоте что-то надето: звезда держится над головой, книга закрывает грудь. Выбор игрока не прячется (`petPictureName`, тест).

| Событие дня (`petState().reason`) | Поза |
|---|---|
| `back` — «С возвращением» | машет крылом |
| `grew`, `goal`, `plan` | держит звезду |
| «Азбука протеза» | читает |
| остальное | картинка настроения: ждёт, рада, спит |

## Как заменить картинку

1. Положить новый PNG с тем же именем в пакет (папка `SYNERGY_GRAPHICS`, рядом с репозиторием, или путь в `--src`).
2. `pip install pillow numpy scipy "rembg[cpu]"` (один раз) и `python tools/import-art.py --sheets ../art-qa`. Маски кэшируются в `tools/.cache/art-masks`. Ключ `--only pet-` перегенерирует одну семью.
3. Открыть `../art-qa/*.jpg`. Там каждая картинка показана на тёмном и мятном фоне, а `outfits.jpg` показывает птицу в нарядах. Если поменялась картинка птицы, сверить глаза в таблице `EYES` инструмента.
4. `npm test`. Тесты `tests/v516.test.mjs` сверяют каталог с файлами (размер из заголовка WebP, байты, SHA-256), бюджеты, «у каждой сущности есть картинка», «нет неиспользуемых картинок», рамки вещей и позы.

- **Вырезание:** контактные листы всех семей на тёмном и мятном фоне просмотрены. После заливки замкнутых поверхностей белые детали на месте, ореолов нет.

- **Экраны:** онбординг, главная, гнездо (наряды, медали, облики), «Прогресс», настройки, «Азбука», цели, опрос, уровни, четыре игры после отсчёта, итоги со всеми видами наград — в светлой и тёмной теме. Битых картинок и ошибок консоли нет.
- **e2e и axe:** 0 ошибок JS, 0 нарушений доступности.
- **Линтер раскладки:** быстрый прогон — 0 находок, полный — число в `MEMORY.md`.
- **APK 5.16.0 в BlueStacks** (Android 7.1.1, WebView на Chrome 119): обложки онбординга, главная с растровыми значками, гнездо с яйцом на ковре комнаты.
