# Сценарии работы и граничные случаи

Спецификация поведения v5: что делает программа в каждом сценарии и чем это проверено.
Принцип: **безопасность → понятность → мотивация**. Если правила конфликтуют, побеждает левое.

## 1. Главный поток дня

```
Онбординг (1 раз) → Первые шаги (обучение, можно пропустить)
        ↓
Главная → «Начать» → Самочувствие (1 раз в день) ─┬─ сильная боль → «Сегодня отдых», план закрыт
                                                   ├─ умеренная боль / сильная усталость → лёгкий план (1 упр. + проверка)
                                                   └─ норма → обычный план (3 упр. + без подсказки; ребёнок — 2)
        ↓
Игра (старт удержанием A) → Итоги (удержание A = главное действие) → Отдых 20 с (ребёнок 15 с) → Игра …
        ↓
Итоги последнего пункта → «Насколько тяжело было?» → Главная (план ✓, +60 XP)
```

| # | Сценарий | Ожидаемое поведение | Проверка |
|---|---|---|---|
| 1.1 | Первый запуск | Онбординг: что это, безопасность, схема управления, сторона протеза, кто занимается (взрослый/ребёнок) → предложение пройти «Первые шаги» | e2e smoke |
| 1.2 | «Первые шаги» | Каждый шаг закрывается сам, когда команда удержана; через 8 с без успеха — подсказка; можно пропустить шаг/всё; по окончании — достижение «Первые шаги» | `tutorial` unit |
| 1.3 | Самочувствие: сильная боль | План не стартует, на главной «Сегодня — отдых» и кнопка «Изменить ответ»; свободная игра доступна с предупреждением | `wellbeing` unit, e2e |
| 1.4 | Самочувствие: умеренная боль или сильная усталость | План сокращается: выполненные пункты + 1 упражнение + проверка без подсказки; метка «лёгкая» | `lightenPlan` unit |
| 1.5 | Самочувствие пропущено | Записывается «пропущено», повторно не спрашивается в этот день | `tests/scenarios.test.mjs` |
| 1.6 | Смена схемы управления в течение дня | План пересобирается под новую схему; если сегодня был ответ «лёгкая», он применяется и к новому плану | `dailyPlan` unit |
| 1.7 | Признаки усталости | ≥ 3 упражнения, ≥ 6 мин и результат упал на ≥ 20 очков от первых двух → на итогах «Пора отдохнуть», главное действие = «Закончить на сегодня», «Всё равно продолжить» — вторичная кнопка | `fatigueSigns` unit |
| 1.8 | Дневной лимит (30 мин, ребёнок 20 мин) | Та же логика, что 1.7; на главной предупреждение | `tests/scenarios.test.mjs` |
| 1.8a | Интервальное повторение | Игра без занятий 7 дней поднимается в плане на 21 очко приоритета, даже если её навык не самый слабый | `spaced plan` unit |
| 1.9 | План выполнен | Кнопка «План выполнен ✓» неактивна, бонус XP начислен один раз | `completePlanItem` unit |
| 1.10 | Полночь во время тренировки | Упражнение записывается в день завершения; серия и план считаются по нему | `tests/scenarios.test.mjs` |
