# Сценарии работы и граничные случаи

Спецификация поведения v5: что делает программа в каждом сценарии и чем это проверено.
Принцип: **безопасность → понятность → мотивация**. Если правила конфликтуют, побеждает левое.

## 1. Главный поток дня

```
Онбординг (1 раз) → Первые шаги (обучение, можно пропустить)
        ↓
Главная → «Начать» → Самочувствие (1 раз в день) ─┬─ сильная боль → «Сегодня отдых», план закрыт; раздражение кожи → план на эмуляторе, без датчиков
                                                   ├─ умеренная боль / сильная усталость → лёгкий план (1 упр. + проверка)
                                                   └─ норма → обычный план (3 упр. + без подсказки; ребёнок — 2)
        ↓
Игра (старт удержанием A) → Итоги (удержание A = главное действие) → Отдых 20 с (ребёнок 15 с) → Игра …
        ↓
Итоги последнего пункта → «Насколько тяжело было?» → Главная (план ✓, +60 XP)
```

| 1.7 | Признаки усталости | ≥ 3 упражнения, ≥ 6 мин и результат упал на ≥ 20 очков от первых двух → на итогах «Пора отдохнуть», главное действие = «Закончить на сегодня», «Всё равно продолжить» — вторичная кнопка | `fatigueSigns` unit |
