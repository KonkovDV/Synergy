# Задача и правила: первоисточник и хронология

Полный текст — Правила хакатона «Моторика: Код движения» на платформе Codenrock: https://codenrock.com/contests/motorika-kod-dvizheniya. В репозиторий документ не включён (объект прав Организатора, п. 5.5). Ниже — дословные цитаты в информационных целях с указанием источника (ГК РФ ст. 1274 п. 1).

## Цитаты

> **Продукт** — работающий функциональный прототип мобильной игры-тренажёра для обучения управлению бионическим протезом посредством ЭМГ-сигналов, включающий в себя интерфейсы, описание функционала, исходный код и минимальный дизайн, созданный в срок проведения Хакатона. (раздел 1)

> 2.2. Целью Хакатона является разработка и тестирование функционального прототипа мобильной игры-тренажёра для обучения пользователей бионических протезов навыкам управления протезом посредством ЭМГ-сигналов в безопасной, понятной и мотивирующей среде. В рамках решения может использоваться схема управления на основе двух ЭМГ-кнопок (пороговый и пропорциональный режим) и/или распознавание 7 жестов.

> 3.1. Общий срок проведения Хакатона: с 9 октября 2026 года, 12:00:00, по 18 ноября 2026 года включительно. … С 28 октября 2026 года, 18:00:00, по 11 ноября 2026 года, 13:00:00 — работа Команд над Задачей и разработка Продуктов.

> 3.7. … Всего будет установлено 5 критериев оценки решения Участников с суммарным максимальным итоговым показателем не более 90 баллов.

> 5.5. Участник гарантирует, что разработанная программа: … 4) не будет содержать изображений, персональных данных, объектов исключительных прав, принадлежащих третьим лицам …

## Что взято из задачи, а что — гипотеза команды

| Элемент | Статус |
|---|---|
| Две ЭМГ-кнопки: пороговый и пропорциональный режим | из задачи (п. 2.2) |
| «7 жестов» | из задачи — **число**; **состав** (покой, кулак, ладонь, щепоть, указательный, ключ, «класс») — гипотеза по описанию Omni Hand; заменяется правкой `src/core/vocabulary.js` после публикации задачи. В открытом коде Motorica Start есть обучение жестам UBI4: покой и **семь** активных, из них четыре — наши позы (`docs/RESEARCH.md` §19). Если «7 жестов» — это они, классов восемь (`PLAN.md` C.3, шаг 8) |
| Основной режим — два канала ЭМГ, жесты не обязательны | **с митапа 21.10.2026** (ниже) |
| Формат эмулятора | неизвестен до 28.10; одна точка адаптации — `parseExternal()`. С митапа: эмулятор каждая команда делает свой; от СППР приходит поток вероятностей жестов |
| 5 критериев ≤ 90 баллов | из правил; сами критерии — гипотеза до 28.10 (`docs/JURY_STRATEGY.md`) |

## Хронология разработки (раскрытие)

| Дата | Что | Где видно |
|---|---|---|
| до 09.10.2026 | v3 — лабораторный MVP команды | `legacy/v3` |
| 17.10.2026 | v4 и v5 — подготовка в период регистрации | первый коммит (импорт архива), `CHANGELOG.md` |
| с 28.10.2026 18:00 | работа над опубликованной задачей | коммиты после 28.10 |

Даты коммитов не изменялись и не будут изменяться. 19.10.2026 по решению команды из истории удалены только старые PNG-скриншоты 5.5–5.7 (24 МБ, в проекте их давно нет): все коммиты, авторы, сообщения и даты сохранены, изменились хэши коммитов; архивы 5.10 и 5.11 с исходной историей хранит команда. Правила связывают Продукт со «сроком проведения Хакатона» (с 09.10, п. 3.1) и выделяют разработку с 28.10. Поэтому до загрузки команда **письменно спрашивает Организатора** (PLAN 0.6), допустимы ли наработки периода регистрации. Если нет — наработки до 28.10 заявляются как собственная предшествующая разработка команды (фон), а оцениваемый Продукт — то, что сделано после 28.10 поверх неё, с отдельным перечнем в `AUTHORS.md`.
