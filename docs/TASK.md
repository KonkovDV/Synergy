## Цитаты

> **Продукт** — работающий функциональный прототип мобильной игры-тренажёра для обучения управлению бионическим протезом посредством ЭМГ-сигналов, включающий в себя интерфейсы, описание функционала, исходный код и минимальный дизайн, созданный в срок проведения Хакатона. (раздел 1)

> 2.2. Целью Хакатона является разработка и тестирование функционального прототипа мобильной игры-тренажёра для обучения пользователей бионических протезов навыкам управления протезом посредством ЭМГ-сигналов в безопасной, понятной и мотивирующей среде. В рамках решения может использоваться схема управления на основе двух ЭМГ-кнопок (пороговый и пропорциональный режим) и/или распознавание 7 жестов.
