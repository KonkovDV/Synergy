# Питч-кит: 10 слайдов, видео 90 с, демо 3 мин

Основа — `docs/JURY_STRATEGY.md` (§3 питч, §4 демо, §5 вопросы). 28.10 сверить с опубликованными критериями (PLAN B.5) и переставить слайды под их порядок.

**Правила (практика демо-дней и наш опыт):**
- Дуга «крючок → проблема → решение → доказательство → что дальше»; без метрик роста история убеждает только честностью: что проверено — показываем, что нет — называем гипотезой.
- Одна мысль на слайд, на слайде ≤ 15 слов, остальное — голосом. Темп речи ≈ 130 слов/мин: 90 с видео ≈ 190 слов.
- Числа — только те, что сверяют ворота (`npm run check:submission`): 474 автотеста, APK 3651 КБ, 33 состояния экранов светлой темы и 10 тёмной без нарушений axe-core. Формулировки о науке — по `PLAN.md` C.2.2: «игровая метрика», «исследование связывало», а не «предсказывает» и не «доказано».
- Живое демо + запасное видео + телефон с APK + ноутбук со standalone HTML (`JURY_STRATEGY.md` §4, PLAN 4.2).
- Слова заказчика со слайдов 6, 7 и 13: цель — точность, сила и координация; на выходе — игра с эмуляцией сигнала для установки и тестирования; четыре части решения — управление, задания, навыки (точность, сила, удержание, переключение), обратная связь. «Стабильно, без критических ошибок» — требование слайда 13. 15 минут эмулятора 23.10.2026: 29 упражнений, 0 ошибок JavaScript, цикл кадров жив, куча выросла на 1,5 МБ (`npm run soak`). На телефоне 30 минут ещё не сняты.
