## 3. Питч (5–7 минут) — формулировки без завышения

1. **Боль (30 с).** От протеза верхней конечности отказываются многие: в австрийской выборке — до 44 % (Salminger 2020); в обзоре по электрическим протезам — около 23 % (Biddiss & Chau 2007). Учиться управлять ЭМГ скучно и тяжело, занятия со специалистом редки, протез приходится ждать.
2. **Инсайт (30 с).** Обзоры показывают: тренировка мышц без структуры задачи протеза не переносится (Garske 2021). Поэтому наша игра повторяет закон управления протезом. Мы измеряем навык без живой подсказки — **игровая метрика**, которую Dupan 2025 связывали с переносом; доказательства пользы именно нашей игры пока нет — это гипотеза для пилота.
3. **Продукт (2 мин, живое демо)** — сценарий §4.
4. **Почему вернутся (40 с).** План дня 10 минут с интервальным повторением, адаптивная сложность (успех ≈ 75 %), затухающие подсказки, серия, которую не ломают ни отдых, ни день боли, видимый рост на еженедельной проверке, отчёт для специалиста.
5. **Технологии (40 с).** Один формат кадра для эмулятора, датчиков, протеза и тестов; офлайн; APK 106 КБ; 95 автотестов, включая модель новичка с реакцией 250 мс — она нашла и помогла исправить перебор силы в пороговой схеме.
6. **ИИ (20 с).** Что сделал ИИ, что команда, как проверено — `docs/AI_USAGE.md`.
7. **Дальше (20 с).** Пилот с реабилитологами Моторики (SHAP, ACMC, время ношения), связка с Motorica Start и Attilan.

Коактивацию (A+B) мы **считаем** по правилу Maas 2024 (оба пика ≥ 40 % МПС, не дальше 350 мс друг от друга). Это способ подсчёта, а не довод, что игра учит: в той же работе фазирование улучшилось во всех группах, включая контрольную, а переноса на тесты с протезом не было. Противоположный результат есть только на малой выборке здоровых участников (Heerschop 2021, 8–10 человек в группе), поэтому эффект нашей игры — гипотеза для пилота с контрольной группой.

## 4. Демо за 3 минуты (и запасное видео 90 с)

Онбординг → «Первые шаги» (кисть повторяет сигнал) → самочувствие «умеренная боль» → лёгкий план → «Мастерская» ур. 1 вручную → итоги удержанием A, без касания → Настройки → «Демо-профиль» → «Прогресс»: проверки навыка, матрица ошибок жестов → «Отчёт для специалиста» (печать/PDF) → Доступность: контраст + 130 % + озвучивание. Запасной план: видео + телефон с APK + ноутбук со standalone HTML.

## 5. Вопросы жюри (Murder Board)

| Вопрос | Ответ |
|---|---|
| Перенос на протез доказан? | Нет. Прототип построен на принципах с лучшей доказательной базой; метрики игровые; проверка навыка — фиксированный протокол для будущей валидации против SHAP/ACMC |
| Ваши «7 жестов» — откуда? | Число — из задачи, состав — гипотеза по Omni Hand; меняется одной правкой словаря |
| Как подключите наш протез / эмулятор? | Кадр `{a, b, gesture?}`: `Synergy.feed`, WebSocket, BLE (NUS), Android `pushFrame` — один парсер `parseExternal()` |
| Почему автотесты проходят «за миллисекунды»? | Это симуляция: бот видит задание и проверяет, что уровни достижимы, а бездействие не даёт звёзд. Отдельно — модель новичка (реакция, шум, провалы). Людей не заменяет — плейтест PLAN 2.1 |
| Дети? | Детский режим: план из 2 упражнений, отдых 15 с, лимит 20 мин, PIN родителя на настройки |
| Безопасно ли? | Опрос боли перед планом → лёгкая тренировка или отдых; признаки усталости; лимит; калибровка на комфортных 70 %; «не медицинское изделие» |
| Данные о здоровье? | Только на устройстве; без сети, аккаунта и аналитики; передача специалисту — действием пользователя (`docs/LEGAL.md`) |
| Почему не открытая лицензия? | Иначе отчуждение права победителем (п. 6.6) обесценится — ранее выданные лицензии сохраняются (ГК РФ ст. 1235 п. 7) |
| Что если сигнал пропал? | Сторож 300 мс: упражнение замирает, кисть держит позицию — это не ошибка пользователя |
| Чем лучше Attilan, Coapt, Sidekick? | Дома, до протеза, без шлема; 3 схемы; проверка навыка и отчёт; доступность (`RESEARCH.md` §5) |
