# Единый язык (Ubiquitous Language)

Термин в интерфейсе = термин в документах = идентификатор в коде (`src/core/vocabulary.js`).

| Термин | Код | Определение |
|---|---|---|
| Канал A · Сжатие | `a`, `COMMAND.CLOSE` | ЭМГ мышцы-сгибателя; закрывает кисть |
| Канал B · Раскрытие | `b`, `COMMAND.OPEN` | ЭМГ мышцы-разгибателя; раскрывает кисть, ослабляет хват |
| Покой | `COMMAND.REST`, жест `rest` | обе мышцы расслаблены; протез держит позицию и силу |
| Коактивация | `COMMAND.SWITCH`, `co` | оба канала ≥ порога коактивации (40 % комфортного уровня калибровки ≈ 28 % МПС) с началом в пределах 350 мс; меняет хват |
| Активация | `intent.a/b` | нормализованный уровень канала 0..1 после калибровки |
| Порог включения | `sensitivity`, `onThreshold` | уровень, выше которого канал «включён» (с гистерезисом) |
| Расслаблен (покой мышц) | `intent.relaxed` | оба канала выключены; отличается от команды REST, при которой протез держит позицию, даже если обе мышцы напряжены без коактивации (5.10) |
| Достижимая полоса силы | `reachableBand()` | полоса силы, перенесённая выше порога включения пользователя; при пороге по умолчанию — без изменений (5.10) |
| Удержание для подтверждения | `HoldConfirm` | старт или «дальше» без касания: после расслабления удерживать сжатие заданное время (5.10) |
| Огибающая ЭМГ · Сырая ЭМГ | `EnvelopeFilter`, `BridgeSource.raw` | контракт кадра — огибающая ≥ 0 (MAV/RMS); первое отрицательное значение означает сырой двуполярный сигнал → источник считает RMS за 150 мс по всем сообщениям (5.9) |
| Площадки без удержания | `stickyPads`, `setPadMode` | режим доступности: касание включает канал или жест, второе касание выключает (тремор, слабость) |
| Системный контраст | `app.systemContrast` | высокий контраст по настройке системы (`prefers-contrast: more`, `forced-colors`), независимо от переключателя |
| Интенсивность | `intent.intensity` | сила текущей команды 0..1 (в пороговой схеме постоянна) |
| Схема управления | `SCHEME` | пороговая · пропорциональная · жесты |
| Жест | `GESTURES` | Покой, Кулак, Ладонь, Щепоть, Указательный, Ключ, Класс — задан только в `vocabulary.js` |
| Активные жесты | `ACTIVE_GESTURES` | все жесты, кроме покоя (6) |
| Путаница жестов | `GESTURE_CONFUSION`, `confusionRow` | веса пар похожих жестов: эмулятор и демо-профиль ошибаются как классификатор |
| Учебная замена | `tools/gesture-drill.mjs` | проверка, что смена набора жестов требует правки одного файла |
| Хват | `hand.grip` | закрывающий жест протеза: кулак, щепоть, ключ, указательный, класс |
| Сила хвата | `hand.force` | условная сила 0..1 (не ньютоны) |
| Окно силы | `min..max` у предмета | зелёная зона, в которой предмет можно поднять |
| Намерение | `Intent` | то, что игра поняла из сигнала в этот кадр |
| Кадр сигнала | `SignalFrame` | один отсчёт источника `{a, b, gesture?, confidence?, effort?}` |
| Источник | `source: touch | bridge` | экранный эмулятор ЭМГ или внешний поток |
| Калибровка | `calibrations` | покой и комфортный максимум каждого канала |
| Подстройка покоя | `RestTracker`, `adaptRest` | покой медленно следует за дрейфом датчика в подтверждённом покое (≤ 20 % диапазона) |
| Пора перекалибровать | `needsRecalibration` | дрейф покоя > 30 % или канал включён > 15 с подряд |
| Сторож | `frameTimeoutMs` | 300 мс без кадров → «Нет сигнала», упражнение замирает |
| Упражнение | `run` | одна завершённая игра на уровне |
| План дня | `profile.plan` | 3 упражнения + испытание без подсказки |
| Испытание без подсказки | `retention` | упражнение со скрытой живой обратной связью (шкала силы, подсветка, планёр); задание — ноты, карточка, кольца, предмет — видно |
| Серия | `streak` | тренировочные дни подряд; один день отдыха не прерывает |
| Недельная цель | `weeklyGoal` | сколько дней в неделю тренироваться (по умолчанию 4) |
| Навыки | `SKILL` | Точность, Плавность, Тайминг, Разделение, Переключение, Без подсказки |
| Мио | `ui/coach.js`, `drawMio` | тренер: правила-подсказки после упражнения; настроение — радость, поддержка, отдых (`coachMood`) |
| Музыка уровня | `musicPattern`, `MusicPlayer`, `music` | процедурная музыка «Ритма» на часах звука с учётом задержки вывода |
| Поза руки | `ARM_POSES`, `pose` (план, упражнение), `poseSummary` | положение руки в испытании без подсказки с датчиками: вдоль тела, локоть 90°, вперёд; меняется от испытания к испытанию, в отчёте — разница с обычным результатом той же игры |
| Объявление подсказки | `LiveAnnouncer` | что слышит скринридер и голос: задание — сразу, как удержится 0,4 с; частая обратная связь — не чаще раза в 1,5 с |
| Сила с клавиатуры | `kbStrength`, площадка `slider` | сила, которую держит клавиша или переключатель: стрелки на площадке или +/−, 10–100 % |
| Дней с занятиями | `trainingDays` | все дни, когда было хоть одно упражнение; не обнуляется, в отличие от серии |
| Синхронизация звука | `audioOffsetMs`, `offsetClock`, экран `audiosync` | ручная поправка задержки звука (мс): плюс — звук слышен позже, чем сообщает устройство, поэтому запускается раньше |
| Адаптивная сложность | `AdaptiveDifficulty`, `ease` | подстройка допусков внутри упражнения под ~75 % успешных попыток |
| Проверка навыка | `check`, `details.assessment` | еженедельный стандартный тест с фиксированным протоколом |
| Время выбора | `selectionMs` | от показа команды до первого верного кадра |
| Время выполнения | `completionMs` | от показа команды до завершённого удержания 1 с |
| Доля выполненных | `completionRate` | выполненные попытки / все попытки, % |
| Индекс трудности | `fittsId`, ID | log₂(D/W + 1), бит: D — уровень силы от покоя, W — ширина окна |
| Пропускная способность (ПС) | `throughputBps` | среднее ID / время движения по выполненным попыткам блока Фиттса, бит/с |
| Эффективность пути | `pathEfficiency` | D / путь, пройденный сигналом до входа в окно, % |
| Самочувствие | `checkin` | боль (NRS: нет / 1–3 / 4–6 / 7–10) и усталость перед планом; с внешними датчиками — и кожа под электродами (`SKIN_LEVELS`) |
| Предупреждение свободной игры | `freePlayCaution` | текст на заставке игры в день отдыха (боль, кожа) или сверх дневного лимита; игра не запирается |
| Лёгкая тренировка | `plan.light` | 1 упражнение + испытание без подсказки |
| Признаки усталости | `fatigueSigns` | падение результата ≥ 20 очков после ≥ 6 мин |
| Страж кадров | `FpsGuard`, `PERF` | < 45 к/с дольше 3 с → упрощённая графика до конца визита |
| Темп игры | `gameSpeed` | скорость игрового мира 60–100 % (кисть — в реальном времени) |
| Первые шаги | `tutorial` | интерактивное обучение базовым командам |
| Детский режим | `audience: child` | план из 2 упражнений, отдых 15 с, лимит 20 мин, PIN родителя |
| Демо-профиль | `showcase` | синтетические данные в памяти для презентации |
| Затухающие подсказки | `guidance`, `fadedFeedback` | доля попыток с живой шкалой снижается по мере роста навыка |
| Интервальное повторение | `SPACING` | давно не игравшиеся игры поднимаются в плане дня |
| Причина настроения (5.13) | `petState().reason` | главное событие дня, которое называет строка Жар-птицы: отдых, новая стадия, цель, план, тренировка, ожидание |
| Реакция Жар-птицы (5.13) | `PET_ANIMATIONS`, `petReaction`, `petTap` | короткая анимация и слова: оживляж, сон, прыжок, взмах, праздник, рост |
| Место · Вещь (наряд) (5.13) | `PET_SLOTS`, `PET_ITEMS` | места на птице и в гнезде (голова, грудь, гнездо) и вещи — подарки за достижения; без валюты |
| Цель недели · Цель от Жар-птицы (5.13) | `profile.mission`, `core/missions.js` | одна выбранная игроком цель из трёх предложенных: условие из словаря, 1–3 шага, награда ≤ 60 XP, без срока |
| Подсказка-тур · Якорь (5.13) | `TOURS`, `TourSession`, `data-tour` | короткая серия подсказок экрана; якорь — имя элемента вида `экран.элемент`, к которому привязан шаг |
