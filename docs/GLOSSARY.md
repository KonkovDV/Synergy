# Единый язык (Ubiquitous Language)

Термин в интерфейсе = термин в документах = идентификатор в коде (`src/core/vocabulary.js`).

| Термин | Код | Определение |
|---|---|---|
| Канал A · Сжатие | `a`, `COMMAND.CLOSE` | ЭМГ мышцы-сгибателя; закрывает кисть |
| Канал B · Раскрытие | `b`, `COMMAND.OPEN` | ЭМГ мышцы-разгибателя; раскрывает кисть, ослабляет хват |
| Покой | `COMMAND.REST`, жест `rest` | обе мышцы расслаблены; протез держит позицию и силу |
| Коактивация | `COMMAND.SWITCH`, `co` | оба канала ≥ порога коактивации с началом в пределах 350 мс; меняет хват |
| Активация | `intent.a/b` | нормализованный уровень канала 0..1 после калибровки |
| Порог включения | `sensitivity`, `onThreshold` | уровень, выше которого канал «включён» (с гистерезисом) |
| Интенсивность | `intent.intensity` | сила текущей команды 0..1 (в пороговой схеме постоянна) |
| Схема управления | `SCHEME` | пороговая · пропорциональная · жесты |
| Жест | `GESTURES` | Покой, Кулак, Ладонь, Щепоть, Указательный, Ключ, Класс — задан только в `vocabulary.js` |
| Активные жесты | `ACTIVE_GESTURES` | все жесты, кроме покоя (6) |
| Учебная замена | `tools/gesture-drill.mjs` | проверка, что смена набора жестов требует правки одного файла |
| Хват | `hand.grip` | закрывающий жест протеза: кулак, щепоть, ключ, указательный, класс |
| Сила хвата | `hand.force` | условная сила 0..1 (не ньютоны) |
| Окно силы | `min..max` у предмета | зелёная зона, в которой предмет можно поднять |
| Намерение | `Intent` | то, что игра поняла из сигнала в этот кадр |
| Кадр сигнала | `SignalFrame` | один отсчёт источника `{a, b, gesture?, confidence?, effort?}` |
| Источник | `source: touch | bridge` | экранный эмулятор ЭМГ или внешний поток |
| Калибровка | `calibrations` | покой и комфортный максимум каждого канала |
| Подстройка покоя | `RestTracker`, `adaptRest` | покой медленно следует за дрейфом датчика в подтверждённом покое (≤ 20 % диапазона) |
| Пора перекалибровать | `needsRecalibration` | дрейф покоя > 30 % или канал включён > 15 с подряд |
| Сторож | `frameTimeoutMs` | 300 мс без кадров → «Нет сигнала», упражнение замирает |
| Упражнение | `run` | одна завершённая игра на уровне |
| План дня | `profile.plan` | 3 упражнения + испытание без подсказки |
| Испытание без подсказки | `retention` | упражнение со скрытой живой обратной связью |
| Серия | `streak` | тренировочные дни подряд; один день отдыха не прерывает |
| Недельная цель | `weeklyGoal` | сколько дней в неделю тренироваться (по умолчанию 4) |
| Навыки | `SKILL` | Точность, Плавность, Тайминг, Разделение, Переключение, Без подсказки |
| Мио | `ui/coach.js` | тренер: правила-подсказки после упражнения |
| Адаптивная сложность | `AdaptiveDifficulty`, `ease` | подстройка допусков внутри упражнения под ~75 % успешных попыток |
| Проверка навыка | `check`, `details.assessment` | еженедельный стандартный тест с фиксированным протоколом |
| Время выбора | `selectionMs` | от показа команды до первого верного кадра |
| Время выполнения | `completionMs` | от показа команды до завершённого удержания 1 с |
| Доля выполненных | `completionRate` | выполненные попытки / все попытки, % |
| Индекс трудности | `fittsId`, ID | log₂(D/W + 1), бит: D — уровень силы от покоя, W — ширина окна |
| Пропускная способность (ПС) | `throughputBps` | среднее ID / время движения по выполненным попыткам блока Фиттса, бит/с |
| Эффективность пути | `pathEfficiency` | D / путь, пройденный сигналом до входа в окно, % |
| Самочувствие | `checkin` | боль (NRS: нет / 1–3 / 4–6 / 7–10) и усталость перед планом |
| Лёгкая тренировка | `plan.light` | 1 упражнение + испытание без подсказки |
| Признаки усталости | `fatigueSigns` | падение результата ≥ 20 очков после ≥ 6 мин |
| Темп игры | `gameSpeed` | скорость игрового мира 60–100 % (кисть — в реальном времени) |
| Первые шаги | `tutorial` | интерактивное обучение базовым командам |
| Детский режим | `audience: child` | план из 2 упражнений, отдых 15 с, лимит 20 мин, PIN родителя |
| Демо-профиль | `showcase` | синтетические данные в памяти для презентации |
| Затухающие подсказки | `guidance`, `fadedFeedback` | доля попыток с живой шкалой снижается по мере роста навыка |
| Интервальное повторение | `SPACING` | давно не игравшиеся игры поднимаются в плане дня |
