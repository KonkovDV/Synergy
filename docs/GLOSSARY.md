# Единый язык (Ubiquitous Language)

Термин в интерфейсе = термин в документах = идентификатор в коде (`src/core/vocabulary.js`).

| Термин | Код | Определение |
|---|---|---|
| Канал A · Сжатие | `a`, `COMMAND.CLOSE` | ЭМГ мышцы-сгибателя; закрывает кисть |
| Канал B · Раскрытие | `b`, `COMMAND.OPEN` | ЭМГ мышцы-разгибателя; раскрывает кисть, ослабляет хват |
| Покой | `COMMAND.REST`, жест `rest` | обе мышцы расслаблены; протез держит позицию и силу |
| Коактивация | `COMMAND.SWITCH`, `co` | оба канала ≥ порога коактивации с началом в пределах 350 мс; меняет хват |
| Активация | `intent.a/b` | нормализованный уровень канала 0..1 после калибровки |
| Порог включения | `sensitivity`, `onThreshold` | уровень, выше которого канал «включён» (с гистерезисом) |
| Интенсивность | `intent.intensity` | сила текущей команды 0..1 (в пороговой схеме постоянна) |
| Схема управления | `SCHEME` | пороговая · пропорциональная · жесты |
| Жест | `GESTURES` | Покой, Кулак, Ладонь, Щепоть, Указательный, Ключ, Класс |
| Хват | `hand.grip` | закрывающий жест протеза: кулак, щепоть, ключ, указательный, класс |
| Сила хвата | `hand.force` | условная сила 0..1 (не ньютоны) |
| Окно силы | `min..max` у предмета | зелёная зона, в которой предмет можно поднять |
| Намерение | `Intent` | то, что игра поняла из сигнала в этот кадр |
| Кадр сигнала | `SignalFrame` | один отсчёт источника `{a, b, gesture?, confidence?, effort?}` |
| Источник | `source: touch | bridge` | экранный эмулятор ЭМГ или внешний поток |
| Калибровка | `calibrations` | покой и комфортный максимум каждого канала |
| Сторож | `frameTimeoutMs` | 300 мс без кадров → «Нет сигнала», упражнение замирает |
| Упражнение | `run` | одна завершённая игра на уровне |
| План дня | `profile.plan` | 3 упражнения + испытание без подсказки |
| Испытание без подсказки | `retention` | упражнение со скрытой живой обратной связью |
| Серия | `streak` | тренировочные дни подряд; один день отдыха не прерывает |
| Недельная цель | `weeklyGoal` | сколько дней в неделю тренироваться (по умолчанию 4) |
| Навыки | `SKILL` | Точность, Плавность, Тайминг, Разделение, Переключение, Без подсказки |
| Мио | `ui/coach.js` | тренер: правила-подсказки после упражнения |
