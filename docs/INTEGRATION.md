# Подключение эмулятора организаторов, датчиков или протеза

## Контракт кадра (SignalFrame)

```json
{ "a": 0.42, "b": 0.05, "gesture": "pinch", "confidence": 0.91, "effort": 0.6 }
```

| Поле | Обязательно | Смысл |
|---|---|---|
| `a`, `b` | да (для жестов можно опустить) | огибающая ЭМГ каналов A (сжатие) и B (раскрытие), ≥ 0. Если не 0..1 — выполните калибровку |
| `gesture` | нет | id (`rest, fist, open, pinch, point, key, thumb`), русское имя (`Кулак`, `щепоть`…, регистр не важен), индекс класса 0–6 (`CLASS_ORDER`) или синоним (`close`, `palm`, `tripod`, `lateral`…) |
| `confidence` | нет | уверенность классификатора 0..1; ниже 0,6 → «покой» |
| `effort` | нет | сила жеста 0..1 (иначе берётся max(a, b)) |

Время кадра проставляется **при получении** — часы источника не важны. Если 300 мс нет кадров — упражнение замирает.

Принимаются и другие формы: `{ch:[a,b]}`, `{channels:[…]}`, `{emg:[…]}`, `[a,b]`, строка `"a b"`/`"a,b"`, `{class|label: …, prob|p: …}`. Номера каналов для A/B в многоканальном массиве задаются в `parseExternal(msg, {channelA, channelB})`.

## Замена набора жестов (день публикации задачи)

Набор жестов задан **в одном месте** — `src/core/vocabulary.js → GESTURES`. Игры, «Первые шаги», легенда, «Проверка навыка», «Сейф», эмулятор, аналитика и мост берут его оттуда. Жест «Покой» сохраняет id `rest`.

1. `src/core/vocabulary.js → GESTURES`: `id`, `name`, `command` (`close`/`open`/`rest`), `grip`, `pose` `[большой, указательный, средний, безымянный, мизинец]`, `introducedAt` (уровень «Сейфа»), `cue` (как показать), `use` (назначение). Порядок закрывающих жестов важен: первый — силовой хват (обучение, поза «сжать»), второй — поза коактивации.
2. `src/input/bridge.js`: `CLASS_ORDER` — если индексы классов эмулятора идут в другом порядке; `GESTURE_ALIASES` — синонимы из эмулятора (id и русские имена принимаются сами).
3. `src/config.js`: `HAND.twoChannelGrips` (если меняются хваты протеза), `GESTURE_CONFUSION` (пары похожих жестов).
4. `src/games/grip.js → OBJECTS[*].grip` — если хвата больше нет.
5. `node tools/gesture-drill.mjs` и `npm test`.
6. Документы: `docs/GLOSSARY.md`, `docs/TASK.md` (статус «из задачи»), `docs/JURY_STRATEGY.md` §1–2 (убрать «гипотеза»), `lab/lab7.py` (классы синтетики), запись набора в `MEMORY.md`.

**Учебная замена** `node tools/gesture-drill.mjs` копирует код во временную папку, меняет в `vocabulary.js` жест «Класс» на «Трипод» и запускает тесты. Ожидаемо падает **только** тест-напоминание, который называет жесты намеренно:

| Тест | Что обновить |
|---|---|
| `vocabulary: bridge synonyms point to existing gestures` | `GESTURE_ALIASES` в `src/input/bridge.js` (шаг 2) |

Пары путаниц (`GESTURE_CONFUSION`) с несуществующими жестами отбрасываются сами; хваты «Мастерской» и `HAND.twoChannelGrips` проверяет `tests/vocabulary.test.mjs` — при удалении хвата он подскажет, где править (шаги 3–4).

## Транспорты

1. **WebSocket** — Настройки → Источник → «Внешний» → адрес `ws://IP:порт` → «Подключить».
2. **postMessage** (игра в iframe/WebView): `iframe.contentWindow.postMessage({type:'synergy-frame', a, b}, '*')`.
3. **JS API**: `window.Synergy.feed({a, b, gesture})`; `window.Synergy.useBridge('ws://…')`; `window.Synergy.state()`.
4. **Android**: в `MainActivity.pushFrame(a, b, gesture)` — вызвать из колбэка SDK/BLE протеза.

## Мост `bridge/ws_bridge.py` (Python 3.9+, без зависимостей)

```bash
python3 bridge/ws_bridge.py --demo                 # сценарий: A, B, коактивация
python3 bridge/ws_bridge.py --demo-gestures        # перебор 7 жестов
emulator_cli | python3 bridge/ws_bridge.py --stdin # любой поток "a b" или JSON по строке
pip install -r lab/requirements.txt && python3 bridge/ws_bridge.py --lab
                                                   # сырая 4-канальная ЭМГ → фильтр 20–450 Гц → признаки
                                                   # (RMS, MAV, WL, ZC, SSC) → LDA 7 жестов → игра
python3 bridge/ws_bridge.py --demo --host 0.0.0.0  # чтобы телефон в той же Wi-Fi видел мост
```

**Безопасность моста.** ЭМГ — данные о здоровье, поэтому мост проверяет заголовок `Origin` (защита от перехвата веб-сокета чужим сайтом, OWASP WSTG). Без условий подключаются нативные клиенты (без `Origin`) и страницы с этого же компьютера (`http://127.0.0.1:*`, `http://localhost:*`). Всем остальным — standalone HTML из файла (`Origin: null`), APK, телефону в сети, GitHub Pages — нужен адрес с токеном, который мост печатает при старте: `ws://IP:8765/?token=…` (вставить целиком в Настройки → Источник → адрес). Постоянно доверенный сайт: `--allow-origin https://team.github.io`. Кадр больше 4 КБ или без маски закрывает соединение; клиент, переставший читать, отключается; клиентов не больше 8. Тесты — `python -m unittest bridge/test_ws_bridge.py`.

В режиме `--lab` площадки на экране игры управляют тем, какой жест синтезирует лаборатория (игра отправляет `{"type":"intent", …}`), а распознаёт его настоящий классификатор — с реальными ошибками.

## Калибровка

Настройки → «Калибровка датчиков»: 3 с покоя, 3 с комфортного сжатия (≈70 %), отдых, 3 с раскрытия. Сохраняются покой и комфортный максимум каждого канала (как «чувствительность датчика» в Motorica Start), предупреждения о слабом сигнале и перекрёстных помехах. Калибровка хранится отдельно для экранного эмулятора и внешнего источника.

**Подстройка покоя** (ко-адаптивная калибровка, `RestTracker` в `src/core/calibration.js`, параметры `CALIBRATION_ADAPT` в `src/config.js`): во время упражнения с внешним источником уровень покоя медленно следует за дрейфом сигнала — только в подтверждённом покое и не дальше 20 % диапазона. Итог сессии сохраняется в `calibrations.bridge` (поле `adaptedAt`). Большой дрейф или канал, «залипший» во включённом состоянии, — повод перекалибровать: игра скажет об этом в итогах. «Проверка навыка» идёт без подстройки, чтобы результаты недели были сравнимы.

## Bluetooth-датчики (v5)

Настройки → Источник «Внешний» → «Bluetooth-датчик (BLE UART)». Сервис Nordic UART `6e400001-…`, уведомления TX `6e400003-…`, строки `"a b\n"` / `"a,b\n"` / JSON — тот же `parseExternal()`. Куски по 20 байт склеиваются (`LineAssembler`), мусор без перевода строки > 512 символов отбрасывается, при обрыве — 3 попытки переподключения. После подключения обязательна калибровка (сырые единицы АЦП 0..4095). Прошивка-пример: `bridge/firmware/esp32_emg_ble/` (ESP32 + 2 × MyoWare 2.0, 50 Гц; **не компилировалась командой**). Web Bluetooth: Chrome/Edge на Android и ПК; не в iOS Safari и не в Android WebView — там `pushFrame()`.

## Нативный мост Android (v5)

`window.SynergyNative.speak(text, interrupt)`, `.stop()`, `.share(name, mime, text)` (системное «Поделиться» вместо скачивания — WebView не умеет blob-загрузки), `.print(title, html)` (PrintManager → «Сохранить как PDF»).
