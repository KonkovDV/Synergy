## Перечень: что сделано с помощью ИИ-инструментов

Автор результата — человек (ГК РФ ст. 1228). Имена моделей и сессий сюда не входят.

| Часть | Объём участия ИИ | Основа от команды |
|---|---|---|
| OSINT и обзор литературы (`docs/RESEARCH.md`) | поиск и сводка источников, вывод требований | постановка задачи, правила геймджема |
| Архитектура и доменное ядро (`src/core`) | код целиком | концепции v3: сторож потока, отказ засчитывать неуверенные кадры, коактивация, «без подсказки» |
| Эмулятор ЭМГ и мост (`src/input`, `bridge/`) | код целиком | идея внешнего host-моста из v3 |
| Лаборатория 7 жестов (`lab/lab7.py`) | расширение до 7 классов | DSP-ядро v3 `lab/signals.py` (фильтр, признаки, LDA) — без изменений |
| 4 игры, UI, стили, звук (`src/games`, `src/ui`, `styles`) | код целиком | постановка, отбор и приёмка — команда; имена — в `AUTHORS.md` |
| Тесты, сборка, APK (`tests/`, `tools/`, `android/`) | код целиком | тесты v3 сохранены в `legacy/v3/tests` |
| Документы и план (`docs/`, `PLAN.md`, `MEMORY.md`) | текст целиком | постановка, отбор и приёмка — команда; имена — в `AUTHORS.md` |
| Сгенерированная графика 5.32: кисти, комнаты, корзина, планер (`public/art/hand-*`, `bg-duo-*`, `bg-grip-*`, `prop-*`) | генерация по промптам ИИ (Figma AI), отбор, вырезка ключа, подключение, полировка интерфейса — `docs/GAME_VISUALS.md` §7–8 | запрос и отзывы команды на снимки, приёмка |
| Иллюстрации 5.16 (`public/art/`, иконки, заставка) | генерация изображений по промптам, отбор кандидатов, перепроверка деталей, вырезка фона и подключение — §v5.16 | файл промптов, эталоны стиля и персонажей, требования к деталям (пять пальцев, число перьев), приёмка |

Чужих ассетов нет. Звук генерируется кодом. Иллюстрации 5.16 созданы генератором изображений по промптам команды (ниже), запасные рисунки — SVG кодом.

## План верификации

| Что | Как | Кто, когда | Критерий приёмки |
|---|---|---|---|
| Логика игр, ядро, правила, документы = код | `npm test`, `node tools/gesture-drill.mjs`, `node tools/check-submission.mjs --draft` | автоматически, каждый коммит (CI — после решения об оплате, `PLAN.md` B.1) | 0 упавших тестов; учебная замена — «OK»; ворота — 0 ошибок |
| Интерфейс: доступность и раскладка | `npm run e2e:a11y`, `npm run audit:layout` | перед каждым выпуском | 0 нарушений axe, 0 находок линтера; числа в README = `docs/evidence.json` (ворота) |
| Встраивание | `npm run e2e:embed`, `npm run verify:embed` | перед выпуском | 10 из 10 проверок; Kotlin и типы React Native без ошибок |
| APK | `VERIFY_API=1 sh tools/build-apk.sh`; установка в BlueStacks | перед выпуском | заглушки = API 29; приложение открывается, данные сохраняются при обновлении |
| Телефоны | APK на 3+ Android-устройства, план дня целиком | команда, до 05.11 | без падений и наложений; звук и вибрация есть |
| Эмулятор организатора | подключить, откалибровать, сыграть каждую игру | команда, 28.10 после 18:00 | кадры идут, сторож не срабатывает зря; формат — одна правка `parseExternal()` |
| Motorica Start | снимок v1 через `MotoricaStartLink.kt` | команда вместе с организатором, если он даст доступ | уровни доходят до игры; пауза при потере связи |
| Скринридер | TalkBack: онбординг, опрос, план дня | команда, до 05.11 | каждое действие озвучено и выполнимо |
| Тексты о здоровье | вычитка медиком или реабилитологом; юрист — маркировка 0+ | команда, до 11.11 | нет медицинских обещаний; совет всегда ведёт к специалисту |
| Живые игроки | протокол H1–H5 (`docs/USABILITY_PROTOCOL.md`) | с экспертами «Моторики», если будет возможность | результаты — только по сессиям (`docs/USABILITY_RESULTS.md`) |
