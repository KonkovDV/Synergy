# Использование ИИ и подтверждение качества

Правила геймджема разрешают ИИ-инструменты при условии, что команда показывает, какие функции разработаны с их помощью, и подтверждает качество. Этот файл — такое раскрытие.

## Что сделано с помощью ИИ-ассистента (Claude, Anthropic)

| Часть | Объём участия ИИ | Основа от команды |
|---|---|---|
| OSINT и обзор литературы (`docs/RESEARCH.md`) | поиск и сводка источников, вывод требований | постановка задачи, правила геймджема |
| Архитектура и доменное ядро (`src/core`) | код целиком | концепции v3: сторож потока, отказ засчитывать неуверенные кадры, коактивация, «без подсказки» |
| Эмулятор ЭМГ и мост (`src/input`, `bridge/`) | код целиком | идея внешнего host-моста из v3 |
| Лаборатория 7 жестов (`lab/lab7.py`) | расширение до 7 классов | DSP-ядро v3 `lab/signals.py` (фильтр, признаки, LDA) — без изменений |
| 4 игры, UI, стили, звук (`src/games`, `src/ui`, `styles`) | код целиком | — |
| Тесты, сборка, APK (`tests/`, `tools/`, `android/`) | код целиком | тесты v3 сохранены в `legacy/v3/tests` |
| Документы и план (`docs/`, `PLAN.md`, `MEMORY.md`) | текст целиком | — |

Внешних ассетов нет: графика и звук генерируются кодом.

## v5 (17.10.2026)

ИИ-ассистент выполнил исследование (веб-поиск: конкуренты, Attilan, наука, право, доступность, дизайн), аудит v4 (найдены и исправлены: занижение «Плавности», отсутствие сохранения отчётов в APK), код всех v5-модулей, стили «Aurora», тесты, CI и документы. Проверки (5.1.0): 70 автотестов, включая модель новичка (реакция 250 мс, шум силы, провалы внимания) — она нашла непроходимость пороговой схемы, исправлено; e2e v5 без ошибок JS, сверка Android-заглушек с API 29, сборка APK. Не проверено: установка на телефоны, прошивка ESP32 на железе, TalkBack/VoiceOver, игра живыми пользователями.

## Что люди обязаны проверить сами

1. Установить APK на 3+ Android-устройства и пройти план дня.
2. Сыграть каждую игру вручную в каждой схеме — баланс под живого человека, а не автопилот.
3. Подключить официальный эмулятор (28.10) и откалибровать.
4. Вычитать тексты: тон, отсутствие медицинских обещаний.
5. Перед сдачей — обновить таблицы выше фактическими результатами.
