# Использование ИИ и подтверждение качества

Правила геймджема разрешают ИИ-инструменты при условии, что команда показывает, какие функции разработаны с их помощью, и подтверждает качество. Этот файл — такое раскрытие.

## Что сделано с помощью ИИ-ассистента (Claude, Anthropic)

| Часть | Объём участия ИИ | Основа от команды |
|---|---|---|
| OSINT и обзор литературы (`docs/RESEARCH.md`) | поиск и сводка источников, вывод требований | постановка задачи, правила геймджема |
| Архитектура и доменное ядро (`src/core`) | код целиком | концепции v3: сторож потока, отказ засчитывать неуверенные кадры, коактивация, «без подсказки» |
| Эмулятор ЭМГ и мост (`src/input`, `bridge/`) | код целиком | идея внешнего host-моста из v3 |
| Лаборатория 7 жестов (`lab/lab7.py`) | расширение до 7 классов | DSP-ядро v3 `lab/signals.py` (фильтр, признаки, LDA) — без изменений |
| 4 игры, UI, стили, звук (`src/games`, `src/ui`, `styles`) | код целиком | _заполнить командой: постановка, отбор вариантов, правки, приёмка — или «нет»_ |
| Тесты, сборка, APK (`tests/`, `tools/`, `android/`) | код целиком | тесты v3 сохранены в `legacy/v3/tests` |
| Документы и план (`docs/`, `PLAN.md`, `MEMORY.md`) | текст целиком | _заполнить командой: постановка, отбор вариантов, правки, приёмка — или «нет»_ |
| Иллюстрации 5.16 (`public/art/`, иконки, заставка) | генерация изображений по промптам, отбор кандидатов, перепроверка деталей, вырезка фона и подключение — §v5.16 | файл промптов, эталоны стиля и персонажей, требования к деталям (пять пальцев, число перьев), приёмка |

Чужих ассетов нет. Звук генерируется кодом. Иллюстрации 5.16 созданы генератором изображений по промптам команды (ниже), запасные рисунки — SVG кодом.

## v5.9 (18.10.2026) — ответ на внешний аудит 5.8.0

ИИ-ассистент разобрал внешний аудит архива 5.8.0 (триаж T0–T7) и закрыл то, что закрывается кодом и текстом: сырая ЭМГ больше не берётся по модулю молча — RMS-огибающая с тестами (T6); один статус RT-7/RT-8 (T3); линтер раскладки прогнан, число записано с датой и средой (T4); в питче сказано, что бот и модель новичка — не пользователи протеза (T5); «Полёт» говорит незрячему, где кольцо; контраст следует настройке системы; площадки без удержания для тремора; e2e без Python, понятный тест иконок, задание CI на Windows. Найдено попутно: сжатие с «залипшей» площадки переходило в следующий экран; при просмотре скриншотов — слова, разорванные посередине на обычных телефонах («Пропорциональны / й»: линтер их не видел, добавлена проверка, 25 групп → 0), и радар навыков, обрезавший свои подписи на любом экране. Не делал по запросу: ФИО (T0), даты коммитов (T1), официальные id жестов (T2), маркировку 0+ (T7 — юрист команды), медицинские назначения и ослабление стопа при сильной боли. Не проверено: CI на GitHub (в том числе Windows), телефоны, TalkBack/VoiceOver, люди с тремором и без зрения.
