Классика моторного обучения (без ссылок — общеизвестные работы): Challenge Point Framework (Guadagnoli & Lee, 2004) → держим ~70–85 % успеха, откат уровня после двух провалов; Guidance hypothesis / reduced feedback (Winstein & Schmidt, 1990) → фейдинг подсказок; OPTIMAL theory (Wulf & Lewthwaite, 2016): автономия, ожидания успеха, внешний фокус → выбор игр, «Лучше, чем в прошлый раз», подсказки про эффект; Self-Determination Theory (Ryan & Deci, 2000) → автономия, компетентность, связанность (отчёт специалисту).

**Удержание пользователя.** Доказательная база по геймификации домашней реабилитации слабая и неоднородная ([PMC11177982](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC11177982/), [мета-анализ PMC9329711](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC9329711/)). Практика Duolingo: первые 7 дней критичны, ценность — видимая серия и обязательство ([блог Duolingo](https://blog.duolingo.com/duolingo-streak-research/), [Lenny's Newsletter](https://lennysnewsletter.com/p/behind-the-product-duolingo-streaks)). **Наука v5.**
- *Проверка навыка* построена по мотивам Motion Test (Kuiken 2009) и TAC (Simon 2011; доля выполненных, время выполнения) — время выполнения виртуального теста сильно коррелировало с SHAP, Box & Blocks, ACMC ([JNER 2018](https://link.springer.com/doi/10.1186/s12984-018-0402-y)); Fitts/TAC сравнение — [Gusman 2017](https://www.iris.sssup.it/bitstream/11382/545812/1/Gusman2017.pdf).
- *Предпротезная тренировка* улучшает навыки управления у здоровых добровольцев, клинических данных у пользователей протезов пока нет; идёт РКИ MyoTrain (30 дней до выдачи протеза, [NCT05888428](https://tundraspace.com/directory/studies/nct05888428)); VR ≈ симулятор ([Technology and Disability 2025](https://journals.sagepub.com/doi/reader/10.1177/10554181241311685)). → честная формулировка в питче: «готовим навык до протеза; эффект на ношение протеза — гипотеза для пилота».
- *Игровые элементы удлиняют сессии, но и чаще ведут к остановке из-за усталости* (Garske 2022, [TNSRE](https://doaj.org/article/d28a93a856cb4f4f8be58bbc83b3ffc4)) → опрос самочувствия, признаки усталости, дневной лимит.
- *Усталость по ЭМГ*: при субмаксимальном усилии амплитуда огибающей с усталостью **растёт** (рекрутирование), поэтому по одной амплитуде усталость не определяем — используем падение результата за сессию.
- *Отказ от протезов*: ключевые причины — надёжность, функция, комфорт, тревога и депрессия ([Prosthesis 2025](https://www.mdpi.com/2673-1592/7/6/167)) → мотивация без давления, видимый рост, отчёт специалисту.
- *Доступность*: WCAG 2.2 (цели ≥ 24 px, альтернатива перетаскиванию, фокус не скрыт) ([Deque](https://www.deque.com/blog/what-wcag-2-2-means-for-native-mobile-accessibility/)); Game Accessibility Guidelines — темп игры, простая схема, крупные цели ([GAG](https://gameaccessibilityguidelines.com/)).
- *Дизайн 2026*: тёмная тема по умолчанию, бенто-группировка, «мягкая тактильная глубина», крупные кнопки, функциональные микровзаимодействия, стекло — точечно ([обзор трендов](https://www.elinext.com/?p=39738)) → стиль «Aurora».
- *Этичная геймификация*: серия без давления (день отдыха и день боли не прерывают), без таймеров-«потерь», без покупок.

**Для плана v6 (PLAN.md, фаза 2):** ко-адаптация «человек + алгоритм» улучшает одновременное пропорциональное управление ([Hahne 2015](https://scinapse.io/papers/2066473592)); стиль визуальных подсказок при сборе данных меняет качество регрессионных моделей, инкрементальное обучение помогает ([UNB 2025](https://unbscholar.lib.unb.ca/handle/1882/38301)); регрессия для 2 степеней свободы ([Hahne 2014](https://uwspace.uwaterloo.ca/items/87163ad4-d70b-4ff3-8c2b-b717e1437432/full)); открытая модель без калибровки на LibEMG + EMG-EPN-612 (CHI ’26, [обзор](https://a11y-paradise.onrender.com/reviews/69e8bd6b08f8b36eebc68d4b)); лёгкая модель-основа TinyMyo для микроконтроллеров ([arXiv 2512.15729](https://arxiv.org/abs/2512.15729v1)).

## 11. Обновление 20.10.2026 (5.17): SOTA тренировки ЭМГ-играми, ощущение игры

**Главное.** Самое обоснованное на октябрь 2026 — не новые «фишки», а две вещи. Первая — честное измерение. Вторая — такая структура практики, для которой есть данные об удержании навыка: отложенная обратная связь, разные положения руки, стандартные задачи пропорционального управления. Перенос навыка на протез по-прежнему не доказан. Цитаты из работ собраны исследовательским поиском по аннотациям и открытым текстам, полные тексты командой не прочитаны.
