# Безопасность

## Сообщить об уязвимости
Не публикуйте детали в issues. Используйте **Security → Report a vulnerability** (private vulnerability reporting) этого репозитория или напишите капитану команды. Ответ — в течение 3 рабочих дней.

## Модель угроз (кратко)
| Поверхность | Риск | Мера |
|---|---|---|
| Внешние кадры (WebSocket, postMessage, BLE, `Synergy.feed`) | DoS, некорректные данные | один парсер `parseExternal()`: лимит 4 КБ, проверка типов/диапазонов, неизвестные жесты отбрасываются; сторож 300 мс |
| Импорт резервной копии | подмена настроек, XSS | лимит 5 МБ, проверка схемы, белый список ключей и типов настроек |
| Отчёт HTML / CSV | XSS, формулы в таблицах | экранирование всех строк, CSP в отчёте; защита от `=+-@` в CSV |
| DOM | XSS | нет `innerHTML`/`eval`: только `textContent` (`ui/dom.js`); CSP `script-src 'self'` в PWA |
| Android WebView | мост JS→Java, локальные файлы | `setAllowFileAccess(false)`, навигация только внутри `android_asset`, `@JavascriptInterface` только у 4 методов, лимиты размера, `allowBackup=false` |
| Приватность | данные о здоровье (самочувствие) | только на устройстве; без сети (кроме выбранного пользователем моста), аккаунтов, аналитики |
| PIN детского режима | — | это «родительские ворота», не защита данных; хранится хэш |

Подробнее: `docs/LEGAL.md` (152-ФЗ, 323-ФЗ), `docs/SCENARIOS.md`.
