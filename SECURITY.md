# Безопасность

## Сообщить об уязвимости
Не публикуйте детали в issues. Пока репозиторий приватный, напишите капитану команды. Когда репозиторий станет публичным, используйте **Security → Report a vulnerability** (private vulnerability reporting: GitHub включает его только у публичных репозиториев). Ответ — в течение 3 рабочих дней.

## Модель угроз (кратко)
| Поверхность | Риск | Мера |
|---|---|---|
| Внешние кадры (WebSocket, postMessage, BLE, `Synergy.feed`) | DoS, некорректные данные | один парсер `parseExternal()`: лимит 4 КБ, проверка типов/диапазонов; класс не из набора — покой с уверенностью 0 и меткой не длиннее 32 знаков, только `textContent` (5.29); имена жестов ищутся в таблице без прототипа (RT-14); сторож 300 мс |
| Импорт резервной копии | подмена настроек, XSS | лимит 5 МБ, проверка схемы, белый список ключей и типов настроек; наряд птицы, цель и состояние подсказок (5.13) — только известные значения; «покой в движении» — доля 0…1 и секунды 0…600; быстрый старт в записи упражнения — только логическое `true` (чужое значение из копии не считается) |
| Отчёт HTML / CSV | XSS, формулы в таблицах | экранирование всех строк, CSP в отчёте; защита от `=+-@` в CSV |
| DOM | XSS | нет `innerHTML`/`eval`: только `textContent` (`ui/dom.js`); CSP `script-src 'self'` в PWA |
| Android WebView | мост JS→Java, локальные файлы | `setAllowFileAccess(false)`, навигация только внутри `android_asset`, `@JavascriptInterface` только у 4 методов, лимиты размера, `allowBackup=false` |
| Приватность | данные о здоровье (самочувствие) | только на устройстве; без сети (кроме выбранного пользователем моста), аккаунтов, аналитики |
| PIN детского режима | перебор ребёнком | «родительские ворота», не защита данных (хранилище всё равно можно сбросить); 4–6 цифр, хэш вместо открытого PIN, **блокировка после 5 ошибок: 30 с → 15 мин** |
| Ключ подписи APK | подмена обновлений | в репозитории ключей нет (`check:submission` проверяет); релиз — своим ключом из секретов CI; локальная сборка — временный ключ в `tools/.cache` с предупреждением |
| Цепочка поставки (CI и релиз) | подмена action или зависимости, подмена файла релиза | GitHub Actions закреплены по SHA коммита (Dependabot обновляет); dependency review в PR; в продукте нет зависимостей времени выполнения; к релизу прикладываются SBOM (CycloneDX) и `SHA256SUMS`, для публичного репозитория — аттестация сборки (`attest-build-provenance`, Sigstore). С 5.29 правила проверяет `npm run check:supply-chain` и ворота: установка без скриптов, `checkout` без токена, точные версии, lock-файл из реестра npm, hash пакетов Python, SHA-256 загрузок; Dependabot ждёт 7 дней после выхода версии (`THIRD_PARTY.md`) |
| Мост и чужой сайт в браузере | чтение потока ЭМГ сайтом (cross-site WebSocket hijacking) | проверка `Origin`: свободно — нативные клиенты и страницы с этого компьютера, остальным — токен сессии в адресе или `--allow-origin`; кадр ≤ 4 КБ, только с маской, ≤ 8 клиентов, отключение «не читающих»; тесты `bridge/test_ws_bridge.py` в CI |
| Сервер и мост в сети | доступ соседей по Wi-Fi | по умолчанию только 127.0.0.1; `--lan`/`--host 0.0.0.0` — явно и с предупреждением; без шифрования — только доверенная сеть |
| Встраивание (5.15): команды хоста, нативные каналы WebView | чужое окно запускает упражнение или подаёт сигнал; сведения о здоровье уходят хосту | команды `synergy-start` / `synergy-frame` / `synergy-ping` — только от встраивающей страницы, самой страницы или нативного `WebMessage` (`trustedMessageSource`); игра и уровень проверяются как адрес; наружу — только числа без самочувствия и имени, `postMessage` — только на origin из `?host=`, в нативный канал — один раз; ошибка или враждебный объект хоста перехватываются (`tests/v515.test.mjs`, `tests/e2e/embed.mjs`) |
| Встраивание с `?host=` (5.27, RT-13) | чужой сайт встраивает игру с чужим `?host=`, запускает упражнения, подмешивает кадры | если хост назвал себя в `?host=`, команды и кадры `postMessage` принимаются только с этого origin |
| Пороги протеза от хоста (5.29) | порог вне шкалы или подменённый порог делает канал «всегда включённым» | приём только чисел 0…255, перевод через калибровку с ограничением 5–90 % диапазона; источник — тот же доверенный канал хоста; игра пороги только читает и ничего не пишет в протез; настройка «Пороги как у протеза» выключает их |
| Самодельные датчики на коже (5.27) | ток утечки через электроды от сетевого питания | в настройках источника и у Мио: только от батареи; компьютер или телефон на проводе к датчику — без зарядного устройства |
